# 学校社会工作（school social work）

这份文件处理"在别人的组织里做社工"这一层。学校不是一间以服务为目的的机构，它是一间以教学为目的的组织，社工在里面是**借位工作**：时间是课表的缝隙，案主每天在别人的班上，成效要用学校认得的语言结算。

**读法**：接一个新校区看 §0 与 §3；写干预计划看 §2；带小组看 §5；处理危机看 §6；做方案论证或读效果研究看 §8；日常自查看 §9。个案流程仍走 `06-casework-process.md`，小组技术仍走 `08-group-work.md`，伦理决策框架走 `05-ethics-and-values.md`。

## 0. 学校社会工作的独特性

五条结构性事实，决定了这个场域的技术必须改造后才能用。

**（1）场域是"学校"，不是"机构"。** 学校的主业是教学，社工服务是**次级场景**（secondary setting）里的附着功能。校历、课表、考试周、教师工作量，这些不是背景，是硬边界。判据：**如果一个方案要成立，必须先改动课表、作业量或评价方式，那它就不是社工一个人能决定的事**——它需要走校内协商，而不是在个案里硬推。

**（2）服务对象是未成年人。** 两道同意同时存在：学生本人的**知情同意/赞同**（assent）与家长或监护人的**书面同意**（consent）。未成年人的自决是有限的、渐进的：年龄越大，涉及自身的信息与选择越应归还本人；但涉及风险、治疗、记录调阅时，监护人仍在链条上。判据：**这个决定，当事人本人有没有实际的表达渠道，而不只是被通知。**

**（3）双重委托人（dual client）。** 你同时对学生/家庭负责，对学校/学区负责。这不是偶发的伦理事故，是岗位的结构常态：教育者护学校，社工护案主，两者的忠诚指向从入职第一天就不完全重合。判据：**冲突发生时，你有没有事先说明过的立场、以及一条可以走的申诉或复核通道**——没有通道的双重忠诚，最后一定倒向付你薪水的那一方。

**（4）教育目标是硬约束。** 学校只为"能回到教室的东西"付费：出勤、成绩与学分、课堂行为、同伴与师生关系、校园安全。任何介入都必须能被**翻译**成这几项。翻译不出来的工作（纯情绪支持、家庭治疗、社区倡导）不是没价值，而是会被读成"额外负担"，在预算季第一个被削。判据：**你能不能用一句学校听得懂的话，说清这件事和上课有什么关系。**

**（5）一个岗位覆盖多校。** 常见配置是全校、甚至全学区只有一名社工。这意味着 micro / mezzo / macro 三层要同时具备：上午做个别会谈，中午进 IEP 会议，下午写拨款或给全体教师做培训。代价是专业支持稀薄、督导可能由教育背景而非社工背景的人提供、以及**危机永远优先于预防**。

五条合起来给一个操作结论：学校社工的核心能力不是"会谈技术更强"，而是**在不属于你的组织里，为一项不属于它主业的功能，持续争取位置与时间**。技术再好，位置没了，服务就断。

## 1. 定位与角色

### 1.1 四项基本任务

跨所有学校社工共通，缺一项岗位就会塌成"谈话的人"。

| 任务 | 落地形态 | 常见退化 |
|---|---|---|
| **向校内他人提供咨询**（consultation） | 与教师、行政、辅导员做个案磋商；在职培训；把干预策略交给每天在孩子身边的成人执行 | 变成"教师来吐槽、社工来听"，无具体可执行的动作产出 |
| **评估**（assessment） | 生态评估：学生＋家庭＋邻里＋学校；结果要能直接支撑三种用途——直接服务、咨询、项目设计 | 只做"情况了解"，产出无法转成目标与基线 |
| **直接干预** | 对儿童与家长，个别、小组、家庭三种模态 | 只做个别咨询，小组与家庭永远排在"有空再说" |
| **项目开发**（program development） | 填补校内外无人覆盖的服务空白；写方案、找经费、建转介链 | 变成"每年写一份没人执行的计划书" |

四项任务的排序不是并列：**评估是所有其他三项的地基**。没有生态评估的直接干预，多数会做在错误的目标上——把课堂管理问题当儿童情绪问题，或把家庭危机当学习动机问题。

### 1.2 多重角色表

角色多不是荣誉，是**越界的入口**。每个角色都自带一种"做得太久就变味"的风险。

| 角色 | 做什么 | 与谁对接 | 该角色的越界风险 |
|---|---|---|---|
| **评估者**（assessor） | 生态评估：个体、情境、支持系统三栏；用优势视角；产出可设计干预的信息 | 学生、家长、教师、校外机构 | 评估变成"给孩子定性"；结论写成缺陷清单，优势栏空着 |
| **个别咨询者** | 情绪与行为调适、自我管理、危机后的个别辅导 | 学生（自愿或转介） | 长期做成了心理治疗，超出执业界限与校内心智健康资源的分工 |
| **小组带领者** | 社交技能、新生适应、愤怒管理、丧亲与父母离异支持；训练学生做同伴辅导员 | 学生小组、家长小组 | 把小组当"批量个案"，成员轮流谈，组内互动没被使用 |
| **家庭工作者 / 家访者** | 长期缺勤的家访、失联家庭的首访、把行为计划延伸到家庭、特殊需要儿童的家内训练 | 家长、监护人、寄养家庭 | 家访变成"上门查岗"，把家庭当执行工具而非共同决定者 |
| **团队成员 / 顾问** | 特殊需要学生的安置、复审、退出；向教师做在职培训 | 教师、行政、心理师、诊断师、语言治疗师 | 在团队里只提供"家庭情况"，不参与目标设定，沦为资料员 |
| **个案管理者 / 转介者** | 转介校外检测与治疗；确认转介"真的接上了" | 社区心理卫生、儿童保护、法院、医疗机构 | 转介即结案；把"已转介"当"已服务" |
| **倡导者**（advocate） | 帮家长理解权利；主动外展不敢进校门的家长 | 家长、学区、社区 | 代家长做决定；倡导变成替家庭发声而家庭本人不在场 |
| **调解者**（mediator） | 学生—家长—学校冲突的结构化调解，避免进入正式申诉 | 家长 vs 学校 | 调解中同时充当学校代表与中立第三方，两边都不可信 |
| **危机干预者** | 自杀威胁、暴力、虐待、严重行为问题、师生死亡事件 | 校园危机小组（心理师、社工、校护，必要时校警） | 危机一个接一个，全部工作被拖进反应模式，预防永久停摆 |
| **法院 / 司法联络人** | 长期缺勤转介后出庭、提交出勤与成绩记录；观护少年的信息桥 | 少年法庭、观护官、法律援助 | 以司法手段替代服务；把家庭推进更深的压力而非更多的支持 |
| **项目开发者 / 资源争取者** | 补服务空白、写方案、建社区资源网 | 学区、社区机构、基金会 | 项目跟着经费走，而不是跟着需求走 |
| **系统内的"翻译者"** | 把社工的问题解决语言译成教育术语；帮教师把目标调到学生真实能力 | 教师、行政 | 翻译变成单向顺从：只把社工话改成教育话，不把教育假设改回来 |

一条经验判断：**一个社工最好只负责一到两个校区**。每个校园有独特文化，外人先难识别、后难理解，而信任关系是能否做成一件事的前提。覆盖面越宽，可见度越低，越容易被当成"每周来一次的外人"。

### 1.3 跨学科团队

**团队构成**：教师、行政、辅导员、校护、学校社工、心理师、诊断师、职业与转衔专家、教师助理、语言治疗师、物理治疗师。边界大体是：校护管个别化健康计划并参与报告，心理师与诊断师管筛查与"能力—表现差距"的证据，转衔专家管离校后跟进，社工管**家庭、社区与系统之间那一段**。

**加入团队的五个运作条件**（缺一项就会退化成"并列发言、各写各的报告"）：
1. **相互依赖**——承认单靠自己的专业拿不到结果；
2. **愿意承担新产生的专业活动**——协作会产生没人负责过的新任务，谁接谁留下；
3. **灵活性**——角色可以随个案重划，不必死守职衔；
4. **目标的集体所有权**——目标不是"某专业的建议"，是团队共同签下的；
5. **对过程的反思**——定期回看"我们是怎么协作的"，而不只看个案结果。

**社工的三条独特贡献**：
1. **三重视角**。把家庭、学校、社区同时带进讨论。团队争论"这个孩子该不该进特殊教育"时，心理师给的是"差距有多大"，社工给的是"他在家和社区里发生了什么、这些怎样变成教室里看到的行为"。
2. **生态评估与社会史**。会前的观察、教师访谈（须顾及课堂规则与教师对该生的期待）、家长访谈（其对家中、课堂、社区行为的看法与对学业的态度），这些是其他专业不做的部分。
3. **翻译与校准**。把干预目标从"教育术语"调回到"这名学生的真实能力"，也把社工的判断翻译成教师第二天能执行的动作。

**在团队里最容易被挤压的功能：能力建设与初级预防。** 挤压有三个机制，都很具体：
- **危机优先**。任何一天出现自伤、暴力、家长冲突，当天计划作废。危机不会排队，预防会。
- **行政与个案吃掉时间**。行政事务常占到三成左右的工作时间；个别咨询是最容易被要求、也最容易计件的服务。一项全国性调查里，社工把"服务学生太多"列为实际与理想落差的主因（约三分之二受访者如此归因）。
- **反馈不回教师**。多数转介来自教师，但"与学生和教师一起会谈"这种最能把咨询接回教室的形式，实际常做的不到一成。转介变成单向漏斗：教师送人进来，收不到任何可执行的回馈，下一次就不送了。

**三种典型协作失败**：行政不知道社工能做什么，于是当"高级助理"用；辅导员把社工当竞争者，于是需要开学初就主动说明角色差异；没有私密空间，咨询变成走廊谈话，专业性与保密性同时破产。

### 1.4 必备技能清单

1. **系统化评估**：个别化、含生态与优势视角、信息可直接转成干预设计。
2. **直接实务三模态**：个别、小组、家庭（外加课堂与全校层面的班级小组）。
3. **通才实务的问题解决过程**：接案—评估问题与识别优势—制定并执行计划—评估成效—结案。
4. **六项基本功**：建立并维持专业关系；收集与评估信息；识别优势；制定改善计划；使用有研究支持的干预；在价值伦理内工作。
5. **自主实务能力**：独立决定工作节奏与内容；无法与同行商讨时仍能依伦理决策；清楚自己的**执业界限**（limits of practice）。
6. **精神疾病与学习障碍的常识**：识别常见表现（抑郁、焦虑、注意缺陷、自闭谱系、品行问题、进食障碍、物质使用），知道共病常见、知道哪些必须转介而不能自行处理。
7. **关系建立**：共情、真诚、积极关注。先有连接，儿童才允许你帮他——这一条在校园里比在任何场域都更硬。
8. **儿童发展与风险/韧性知识**：自杀预警信号、虐待与忽视征象、悲伤与创伤征象。缺这一块，最容易把创伤误读成多动、把抑郁误读成懒惰。
9. **本校与学区的需求知识**：能对教师与行政做在职培训，讲的是他们班上的事，不是教科书。
10. **可见度经营**：进家长教师组织、出席校务会议、给教师开课、承担学校层面的委员会工作。

### 1.5 法律与政策授权

下表只写**功能**，不写条文。具体适用范围、门槛、时限、豁免，**以所在地现行法规为准**；跨制度移植时，须先做一次"功能等价物"对照，不能照搬。

| 授权领域 | 要求学校做什么 | 社工因此有什么义务 |
|---|---|---|
| **特殊教育相关法规** | 为符合条件的学生提供免费且适当的公共教育；最少限制环境；非歧视性评估；程序性保障与家长参与权 | 懂法才能有效工作；在会议上替家长解释这几条；确保评估工具与施测者合格、文化公平；协助学校履行对"有特殊需要与无特殊需要学生"的双重义务 |
| **早期干预与学前服务** | 识别 0–6 岁的发育风险并提供早期服务；服务计划须写明家庭资源、优先事项与预期结果 | 参与筛查、治疗计划与资源连结；把"家庭"当服务单位，而不只是儿童；建社区识别网络 |
| **反歧视型法规** | 不得因身心状况排斥或区别对待；对未达特殊教育门槛但确有需要者提供**便利**（accommodations） | 为这类学生争取普通班内的调整（延长考试时间、减量作业、个别帮助、座位与作息调整） |
| **强制入学与出勤法规** | 要求适龄学生持续入学；长期缺勤须介入，必要时转介司法或行政程序 | 先查明原因再谈转介；转介后须提交出勤与成绩记录、出庭；用可控的日常记录支撑举证 |
| **虐待与忽视的强制报告** | 学校人员发现合理怀疑即须报告，未报告可能承担民事、刑事或纪律后果 | 只要"合理、善意的怀疑"就报；遵守"谁听到谁报"的规则（见 §4.1）；保存时间、案号与后续追踪记录 |
| **记录与隐私** | 学生的教育记录受保护，调阅须授权；特定情形可被依法调取 | 服务开始就说明保密的限度；书面同意后才向校外机构传信息；小组场景须书面告知例外 |
| **成年过渡与权利转移** | 到达法定年龄时，部分决定权由监护人转给学生；须提前告知 | 提前一学年做告知与准备；确保学生理解"哪些权利要自己行使了" |

一条实务推论：**法律知识本身就是角色扩张的资源**。懂法之后，"协助其他教育者、学生、家长理解其法定权利与责任"会打开大量工作空间——做在职培训、教教师设定"匹配真实能力"的目标、帮家长读懂计划书、在与普通教育的张力之间做联络人、对接职业康复系统。反之，不懂法的社工只能在被指派的事情里工作。

### 1.6 学校场域特有的伦理困境

六类，每类一句判据。判据的用法是：**答"是"就说明你已经在困境里，不是在准备进入困境。**

1. **经费驱动的信息扭曲。** 社工被暗示不要向家长提校外服务，因为学区可能要为此付费。
   *判据*：你给家长的信息，会不会因为你所属单位的成本而少了一项？
2. **问题成因在校外，服务范围只在校内。** 家庭与社区的成因被要求用校内的、对儿童本人的工作来解决。
   *判据*：这个介入能让造成问题的那一方（家庭、课堂、制度）发生任何改变吗？
3. **保密在非社工场景中失效。** 同事不理解保密，办公室是共用的，谈话在走廊发生。
   *判据*：这次谈话若被第三位同事听见，学生会不会受损？
4. **被非本专业人士督导。** 标准要求由具社工资质者督导，现实中常由教育背景的管理者督导；教育者护学区，社工护案主。
   *判据*：督导给出的指令，是在保护学生还是在保护单位？你有没有把它记录下来的习惯？
5. **"贴标签"与"拿到资源"的两难。** 家长怕被标记而拒绝评估，拒绝就失去服务。
   *判据*：你有没有把"评估—测试—安置"的每一步讲清楚，让家长在理解之后才做决定？
6. **报告义务 vs 信任。** 报告可能带来遣返、失去照护者、家庭破裂等次生伤害，尤其在不稳定居留身份、家暴、物质滥用家庭中。
   *判据*：你是否事先说明了报告的限度，并在报告后仍留在孩子身边？

补充两类常被忽略的：
- **诊断话语的责任**。一旦社工对孩子说"他有精神障碍、需要检测或用药"，单位可能因此承担付费责任。可用的表达是"孩子表现出可能提示某些困难的特征，准确判断需要由有资质的临床人员做出；若判断成立，有些帮助方式确实有效。我可以帮你转介到会与你讨论这些选项的人"——既传达需要，又不构成正式建议。
- **记录的结构性风险**。记录被依法调取、家长要求查看自己孩子的信息，都是保密的常规例外。写记录时就假定它有一天会被当事人读到：**写事实、写观察、写你做过的动作，少写推断与评价。**

## 2. 生态—发展框架

### 2.1 三层结构与"重叠脉络"

框架不是一张图，是一组**评估工具**。三层是：**家庭—学校—社区**（社区含邻里、课后托育、宗教场所、同伴网络、服务机构）。

**三方评估**（tripartite assessment）把学生放进三栏里看：

| 栏位 | 问什么 | 如果不问会怎样 |
|---|---|---|
| **个体因素** | 气质、发展水平、健康状况、既往创伤、语言能力、学习技能 | 把系统问题当成个人缺陷 |
| **情境因素** | 课堂规则、教师期待、座位与时段、校园氛围、家庭当前压力 | 漏掉"问题由学校自身制造"的情况 |
| **支持系统因素** | 家里有谁能帮、社区有谁在、校内有哪个成人跟他有关系 | 设计出无人执行、无人强化的计划 |

三方评估最实用的价值，是能识别**学校自己制造的问题**：与某位教师的坏关系、某节课刚好卡在药效消退的时段、某个座位正对走廊噪音。这类因素在"儿童评估"里永远看不到。

**重叠脉络**（overlapping contexts）的三条含义：
1. 入学后，儿童生活的两大系统是家庭与学校；系统越多，他要掌握的角色越多，冲突也越多。
2. 重叠不是说三个圈相交，而是说**同一个症状可以在任一脉络里生成，也可以在任一脉络里被缓解**。一个"上课不听"的行为，可能生成于家里的睡眠不足、生成于课堂的难度错配、也可能生成于两者叠加。
3. **变化本身是风险**：社区暴力、对校园安全的担忧、离婚与再婚、重组家庭、监护权争议，都会外溢成学业表现问题。评估要问"最近有什么变了"，而不是只问"现在有什么问题"。

**贫困的作用要说到机制层。** 笼统说"贫困影响学业"没有操作价值。更有解释力的说法是**语言语域**（register）：低收入与少数族裔儿童在家里较少接触正式语域，不熟悉学校所需的句式、句法与词汇；话语模式偏向非正式、绕圈子的表达，容易让教师烦躁，进而被读成"表达能力差"或"不专心"。同一层机制还有：拥挤或不安全的住房、交通不足、持续的钱的焦虑、食物与营养不足、医疗负担、对犯罪与安全的持续担忧、依赖邻里生存、与多个服务机构持续打交道。这些不是道德评价，是**认知负荷**——它们占用的正是学习需要的那部分注意力。

### 2.2 有效干预方案的准则

**A. 计划的形式准则（八条）**

1. 明确写出**谁**在**什么时候**、**如何**完成**什么**；
2. 必须有**具体目标**，不用"改善情绪"这类无法判定的表述；
3. 目标由学生参与选定并排序——这既是效果要求，也是价值要求；
4. 第一个目标应针对"当前最影响他与教师、同伴关系"的行为，而不是最容易改的行为；
5. 目标拆小，先做最容易的步骤，制造即时进步感；
6. 达成后有**跟进计划**，检查长期效果，不随结案结束；
7. 建立**测量计划**：基线加持续记录，用图表呈现变化；
8. 用课堂观察的基线数据证明成长——不是社工觉得好了，是数据与教师都说好了。

**B. 三件目标可视化工具**

- **目标图表**：纵轴为 1–10 的自评量表，横轴为报告卡周期内的周数；每周由学生自评达成度，与社工一起标点。周期与学校报告卡对齐，学校系统才消化得了。
- **行为契约**（contingency contract）：写明目标、奖励、双方签名与日期。**不持续执行就不起作用**——这是这类工具唯一的关键。
- **层级系统**（level system）：通常四级，从最低权限起步，按预定标准（安静坐好、整节课工作、带齐书本、听从指令）积分升级，权限递增。社工的角色是帮教师把层级"裁剪"到这名学生的目标行为上，而不是另建一套。

**C. 内容准则：正向行为支持九项**

功能性行为评估（functional behavioral assessment, FBA）、目标设定、契约、正向强化、小组相倚（group contingencies）、跨年龄辅导、同伴中介辅导、高概率请求（先让学生做他很可能答应的事）、有限选择下的自主决策（自我评价、自我监控、自我记录、自我管理）。

九项的共同逻辑：**先改变环境与前因，再要求孩子自控。** 只做第九项（教孩子自我管理）而不做前八项，是最常见的偷工减料。

**D. 前置的评估工具清单**

初诊提纲（主诉、症状、精神状态、学业表现、社会功能、风险因素、家族困难、发展史、优势）；社会史（含午餐室观察同伴接纳）；文化图谱（culturagram，十因子：迁移背景、居留身份、语言、家庭角色、教养方式、节日与仪式、饮食、健康信念、宗教、对服务的态度）；家系图（genogram）；附带信息来源（须先取得书面同意）；创伤史；家庭韧性因素；行为观察（5–10 分钟间隔、上午下午各一次、跨科目、跨日）；功能性行为评估。

### 2.3 各年级段发展议题

| 阶段 | 发展议题 | 该阶段最容易误判的事 |
|---|---|---|
| **学前–入学初** | 分离与依附；语言与运动里程碑；自我调节的萌芽；对作息与秩序的安全感 | 把分离焦虑当"娇气"；把双语习得过程当语言迟缓 |
| **低年级（约 1–3 年级）** | 依恋与安全感；社交技能与社交胜任；注意与冲动的调控；早期学业自我概念（"我是不是笨"在这里定型） | 把注意缺陷当不努力；把创伤后的退缩当"乖" |
| **中年级（约 4–6 年级）** | 同伴评价开始压过成人的评价；发展迟滞的差距显性化；青春期身体变化（女孩前额叶成熟普遍早于男孩一年半左右）；性别间成熟度差异 | 把关系性欺凌当"女孩子闹别扭"；把成绩下滑只当学业问题 |
| **初中（约 7–8 年级）** | 身体意象与自我概念重构；自主性上升而监管下降；同伴群体成为主要归属；风险行为与自主需求同时上升 | 把自伤当"求关注"；把放学后无人监管的时段当家庭私事 |
| **高中（约 9–12 年级）** | 成人式决定与成人式后果首次同时出现；学分开始计入毕业；行动自由扩大；性身份认同；亲密关系脚本；毕业与转衔 | 把"放弃"的语言当青春期口头禅；把转衔当毕业那一年才开始的事 |

跨阶段的机制性议题：**转衔本身就是焦虑源**，小学升初中、初中升高中尤其如此，对发展落后、寄养或亲属照料中的儿童更是。可行做法是原校社工提前通知新校社工或辅导员、安排学年末参观、新校社工先见面答问。这三件事成本很低，但需要有人负责。

### 2.4 把框架转成一份干预计划：六步

1. **接案与关系建立。** 小谈破冰 → 找私密空间 → 从学生所在处开始 → 给学生"疑点利益"、不显怀疑 → 确定最重要的目标 → 签契约 → 固定时段（避开他本来就跟不上的课）→ 守约。
2. **三方评估。** 个体、情境、支持系统三栏各写一遍，并对每一栏都问"这一栏是否可能是主因"。
3. **补文化与家庭结构信息。** 文化图谱、家系图、家庭韧性清单。目的不是"了解背景"，是找出**可以被动员的资源**与**已经被结构性堵住的部分**。
4. **取得可量化基线。** 多次、多时段、多科目的行为观察，加功能性行为评估（行为是什么、何时发生、前因、后果、孩子从中得到什么）。
5. **写问题陈述并分层结果。** 一句话，可观察、可计数。再分短期（每周爆发次数降到零、每节课开始做作业）、中期（找到愤怒的正向出口、完成转介评估）、长期（全科及格、加入一个社团）。
6. **执行、监控、结案与跟进。** 目标图、行为契约、层级系统三件工具任选或叠加；结案要有正式动作（证书或口头确认），一个月后回访，教师端接手巩固。

六步里最容易跳过的是第 4 步。没有基线，第 6 步的"有效"就只是印象。

## 3. 在校内系统里工作

### 3.1 角色分歧从哪来

分歧不是人际摩擦，是**分工本身生产的**。三个结构性来源：
1. **时间感不同。** 完整评估需要时间，学校要"马上告诉我这孩子怎么了、怎么办"。这个落差不会被说服消除，只能被**中间产品**填补：先给一个可执行的临时方案（本周先做什么），再给完整评估。
2. **归因不同。** 学校倾向归因于个体（不努力、家长不配合），社工倾向归因于系统（课堂管理、学校氛围、贫困）。调查证据很稳定：社工把学生问题归因于个体风险因素的比例，明显高于归因于系统因素。
3. **问责对象不同。** 教育者向学区与考核负责，社工向案主负责。同一条建议，一个人算"合规"，另一个人算"失职"。

两个放大器：**资源约束**（没有资源时，评估建议做不出来，社工夹在"该做的"与"能做的"之间）；**专业可见度低**（行政不知道如何"使用"社工，尤其当一个社工服务整个学区时）。

应对的顺序是：**先承认归因差异是真实的，再把它变成分工**——"你负责说这孩子在课堂上做不到什么，我负责说为什么、以及家里和社区能改什么"。不要试图证明谁对，那是在争专业主权，不产生服务。

### 3.2 个别化教育计划（IEP）与便利型计划的差别

**IEP 的流程与社工的位置**

- **前置条件**：多数特殊教育服务要求证据显示**能力与表现之间存在差距**，或显示学生对一般教学干预无反应（后者是"干预反应"路径，见 §8.4）。
- **法定参与人**：家长、学生（有意愿时）、学校行政、特殊教育教师、普通班教师、能解释评量结果的人、学区代表、提供转衔服务的外部机构代表、其他具备该生知识专长的人。辅导员、心理师、社工常被邀请。
- **会议要回答三个问题**：该生是否有符合定义的障碍？障碍是否对其教育造成不利影响？其需要能否通过特殊教育与相关服务满足？
- **安置是一条谱系**：普通班内支持 → 资源教室与抽离式课程 → 分离式班级或学校 → 住宿机构、家中、医疗机构。
- **社工的位置**：委员会通常决定社工的服务目标；**一旦社工目标被写入计划，社工必须参加年度会议并报告每项目标的完成率**。会前，社工的核心贡献是社会史与生态评估——观察学生、访谈教师（要顾及课堂规则与教师对该生的期待）、访谈家长（对家中、课堂、社区行为的看法，以及对学业的态度）。

**两种"计划"的差别**

| 维度 | 个别化教育计划（IEP） | 便利型计划（accommodations plan） |
|---|---|---|
| 法规性质 | 教育拨款与特殊教育权利 | 反歧视（平等参与） |
| 门槛 | 须符合特定障碍类别，且需要特殊教育 | 身心状况显著限制一项以上主要生命活动（含学习） |
| 产出 | 个别化计划、安置、相关服务、目标与进度报告 | 主要是普通班内的调整：延长考试时间、减量作业、个别帮助、座位与作息调整 |
| 典型人群 | 自闭谱系、智力障碍、情绪与行为障碍、感官障碍等 | 未达特殊教育门槛但确有功能影响者（如注意缺陷但学业尚可） |
| 谁负责 | 多专业团队，年度复审 | 通常由校内小组制定，程序较轻 |
| 社工角色 | 评估贡献者＋目标执行者＋年度报告人 | 争取与监督调整是否真的落地 |
| 常见失败 | 目标写得漂亮，课堂没人执行 | 调整写在纸上，教师不知道或做不到 |

两者都可能"双重特殊"：既有障碍又有突出能力的学生，需要更宽的组合，而不是二选一。实务上社工要盯的不是"有没有这份文件"，而是**文件上的每一条，在教室里由谁、在什么时间、怎么执行**。

### 3.3 风险学生的识别指标

四类，任何一类亮三项以上就该启动评估，而不是继续观察。

| 类别 | 指标 |
|---|---|
| **学业** | 成绩在某一科突然跌落（而非缓慢下滑）；成绩下滑通知应同时抄送社工；重复选课或学分不足；已发毕业预告却可能不过关；长期"作业残缺"而非"作业差" |
| **行为** | 攻击前兆变密（激越、挑衅、盯视、摔门）；自伤痕迹（割伤、烧灼、拔毛、抠皮）；体重与进食行为剧变；物质使用的迹象；出勤碎片化（不是完全不來，而是来时来时不来）；突然的穿着、符号、手势变化 |
| **关系** | 被稳定地孤立；突然与原有同伴群体断开；在班上"没有一个人会找他"；约会关系中的控制与恐惧；对某个成人的持续回避（可能是侵害信号） |
| **家庭** | 照护者精神疾病、物质滥用、入监；寄养或监护变动；无家可归或频繁搬迁；家中死亡或重病；家庭暴力；兄弟姐妹已被安置 |

**结构性风险**要单独看：无家可归、贫困、物质滥用环境，这些本身不是"信号"，但它们让上面四类的每一条都更脆弱。累积风险理论的意思很直白：**风险数量比单一风险更能预测结果。**

**行为教导计划五步**（用于高风险学生的通用工具）：指明行为期望 → 解释期望 → 提供结构化练习机会 → 对问题情境做"预先纠正"（pre-correction，在可能出错之前先提醒并演练）→ 对表现出期望行为给予强强化。浓缩版：**告诉他们你要什么，做给他们看，练，强化。**

### 3.4 家长障碍与文化差异的处理

先把"不配合"这个词去掉。**缺席家长会的家庭，多数不是不在意，是被压垮了**——同时在应对贫困的全部挑战与多个机构的表格。把它读成"抗拒"，后面的所有介入都会做错方向。

**参与障碍的具体形态**：工作与第二份工、照顾其他孩子或老人；语言、对本地教育惯例不了解、交通困难；居留身份不稳定者怕被发现而不敢接触系统；有过被机构伤害的经历。

**四个动作**：
1. **把服务单位从孩子改成家庭。** 用优势视角、给选择、支持整个家庭；直接问"你们现在最需要什么"，不做文化假设。
2. **承认对"孩子的困难"有不同理解。** 让家庭讲他们知道什么、认为什么有帮助；跟家长谈"问题行为"时，家长可能听成对其教养质量与家族名誉的指责——开场就要把评价与描述分开。
3. **把策略匹配到家庭的具体关切**，而不是匹配到机构的服务清单。家长关心"他会不会被欺负""能不能毕业"，就先从这里入手，再谈情绪。
4. **降低信息门槛**：推动学校给家长月度日历与通讯（校历、班级事件、全校活动）；重要文件配口头说明；必要时用口译，但**只有翻译不够**——家长需要的常常是"文化经纪人"，把"这个词翻过来了，但我仍不理解这个系统怎么运作"补上。

文化差异要按**互动的强度与质量**衡量，不是按频次。有的家庭很少来学校、很少帮做作业，但对教育期望更高、对成绩的规则更严；有的家庭参与度高但方式与学校期待不同。用"来几次"当指标，一定误判。

### 3.5 如何提高在校可见度

这是本文件最实操的一节。核心原则：**可见度不是宣传出来的，是教师从你这里拿到过能用的东西。**

**七个具体切口，按成本从低到高：**

1. **开学初的十分钟。** 在全体教师会议上用十分钟说清三件事：我做什么、我不做什么（尤其与辅导员的差别）、你怎么找我。不要讲理念，讲"什么样的学生适合转给我"。
2. **接住成绩下滑通知。** 请教务把下滑通知抄送社工，社工在三天内判断是家庭干扰、技能缺陷、还是关系问题，把判断回给教师——**这是一条能被反复使用的固定管道**。
3. **"与学生和教师一起会谈"。** 这是最有效却最少人做的形式（常做的不足一成）。做法很简单：不单独约学生，也不单独找教师，而是三个人坐在一起，把"课堂上发生了什么"当场对齐，产出两条各自要做的动作。
4. **把咨询目标写成课堂动作。** 不说"提升情绪调节能力"，说"数学课前三分钟可以离座喝水，回来坐下不讲话，连续五天"。教师能执行的才是目标，其余都是愿望。
5. **给教师一份"转介前先试三件事"的清单。** 例如：换座位、把任务切成两段、给一次私下确认。教师试过再转介，转介质量会明显上升，也减少"社工是来评判我"的防御。
6. **走廊与转衔时段在场。** 课间、午餐、放学前十五分钟，是关系与信息同时出现的时候。站在固定位置，一周就能被学生认出来。
7. **在教师休息室固定出现。** 不是去聊天，是去被看见。危机之后的一个月尤其重要。

**一条反向纪律**：不要用"我很忙"解释缺席。学校判断一个岗位的价值，看的是"出事时他在不在"，而不是"他做了多少个案"。这也是为什么危机总会挤掉预防——你得主动为预防留出**不可被征用的时段**（例如每周固定两个半天只做课堂与团队层面的事，写进校历）。

**跨年级的一条主线**：所有年级的有效介入，都同时动三样东西——**一个能预测的日常结构**、**至少一个稳定的成人关系**、**一项能被学生自己看见的进步**。缺任何一样，效果会在结案后两个月内消退。

### 4.1 儿童虐待与忽视：识别与报告

**门槛是"合理、善意的怀疑"，不是"确认"。** 不需要证据链，不需要问清全部细节，不需要先与家长对质。未报告可能带来民事赔偿、刑事后果或纪律处分。

**身体征象**：瘀伤（尤其成形状的，如带状、扣状）、齿痕、烫伤（烟头状、对称状）、多处骨折、腹部瘀伤、生殖器或肛周撕裂与擦伤。**最重要的软指标是"伤情与解释不符"**——包括解释随时间改变、解释与发展水平不符（婴儿不会自己摔成那样）、以及不同照护者给出不同版本。

**"揭发见证人"（outcry witness）规则**：多数制度要求**实际听到孩子陈述的那个人自己报告**。因此教师来请社工"代为报告"时，标准答案是"不行"，正确做法是**陪教师一起报告、逐句引导**。这一条最容易做错，也最容易让教师与社工同时违规：社工代报，教师未报；或社工以为已经报了，教师以为社工报了。

**八步操作链**：
1. **开放式、非诱导性提问**（"跟我说说这是怎么弄的"，不问"是不是他打的"）；
2. **带至校护处验伤并拍照**（拍位置与比例，不拍面部识别信息；记录拍摄时间）；
3. **逐项记录**：位置、大小、颜色、形状、孩子原话（用引号，不改写）；
4. **填写本单位/学区规定的报告表单**；
5. **电话或线上向儿童保护机构报告，记下案号、接报人、时间**；
6. **在规定的短时限内完成**（常见为 24–48 小时，以所在地法规为准）；
7. **两周无回音则主动追问**，并记录追问结果；
8. **向孩子解释进度**——直接而诚实的解释（"这件事已经告诉能保护你的人了，他们可能会来问你"）通常使孩子安心，含糊其辞反而增加恐惧。

**报告的限度要事先知道**：儿童保护机构常以"家庭保全"为原则，尽量不拆散家庭；社工可能陷入"虐待—报告—介入—再虐待"的循环数年。这不是报告无用，而是**报告只是入口，后面需要长期的关系与资源**。同时要做好准备：报告后家庭可能立即退出服务，此时保持接触比完成流程更重要。

### 4.2 自伤与自杀风险

**自伤**：校园里常见的是表浅到中度自伤，三个亚型——强迫型（拔毛、咬甲、抠皮、抓挠，常与强迫症状相关）、偶发型、重复型。**偶发转为重复，有时只需五到十次**，所以第一次发现就介入，不要"观察一段"。

自伤与创伤高度相关：目睹或经历身体/性暴力、家庭暴力、重要他人死亡、入监或遗弃、言语虐待、身体或情感忽视、照护者酒精或物质滥用、父母离异。干预不是"禁止"，是**功能替代**：技能训练（正向应对、问题解决、愤怒与压力管理、沟通）加认知行为取向的工作，加功能性行为评估找到这个动作在替他做什么（降焦虑、止痛、自我惩罚、让人看见）。

**自杀风险**：想自杀的青少年常处于矛盾状态，多数会以某种方式发出信号，且通常会回应帮助。要看的信号包括：直接或半直接的语言（"我不想在了""没有我会更好"）、把重要物品送人、突然的平静（可能意味着已决定）、成绩与出勤的骤变、既往未遂史、同伴或家人的自杀史、以及**同伴间的约定**（自杀协议，suicide pact）。发现约定时，要把涉及的所有人都当作独立的风险个案处理，因为"其他人也可能很快伤害自己"。

**不自杀契约**（no-suicide contract）的用法要说清：它是**评估工具，不是防护措施**。学生拒签不是"失败"，是**升级的依据**——立即联系监护人、要求"不要让他独处"、由监护人送医评估、同时安排学业上的兜底（补课、延期、替代作业）。签了也不能就此放心，契约不替代监护。

**学校能做的三件事**：一是建立"找谁"的路径（一个具体的名字、一个具体的房间、一个不需要解释就能进的时段）；二是把风险学生的课表排进"擅长带困难学生"的教师班里；三是返校衔接——住院或长期缺勤后返校，最需要的是**可预测的日常**与**不追问的同学**，这两件事都要提前布置。

### 4.3 辍学与转衔

辍学不是一次决定，是一条**逐步脱离**的路径：出勤碎片化 → 某一科掉队 → 失去活动资格或学分 → 羞耻与回避 → 彻底不来。

关键的结构事实：**到了法定离校年龄之后，司法与儿童保护系统的杠杆同时减弱**。此前可以转介法院、可以要求社工跟进；此后学校手里的工具只剩关系与说服。所以真正的窗口在**初中到高中低年级**，不是毕业班。

可用的做法：出勤的日常监控（每日教师签到表，比月度统计有效得多）；查明原因是**能力问题、关系问题、还是家庭与生计问题**——三者的介入完全不同；把"回校"的门槛降到最低（先来一节课、先来半天）；恢复学分与替代性毕业路径；对已经工作的学生做"在职＋在学"的组合。

**转衔**（transition）要提前：计划团队应在学生约十四岁时开始处理转衔议题，十六岁前明确"离校后要成功，需要哪些服务、由谁提供"。多数制度在成年时把决定权转给学生，学生须在权利转移**至少一年前**被告知——这一年的告知，常被完全漏掉。

### 4.4 寄养与监护变动

寄养与监护变动的影响不在"换了地方住"，在**连续性的断裂**。有追踪研究显示，离开寄养系统的青年中，未完成高中学业、接受特殊教育、留过级、读过三所以上小学的比例都显著偏高。原因很直接：每次转学都丢掉一部分学分、一部分关系、一部分"我是谁"。

社工的四个动作：
1. **把教育稳定性当成一个可谈判的议题。** 能否不转学（保留原校就读）、能否在转学前把学分与课程记录带走、能否让新校在开学前就知道这个孩子的需要。
2. **做"跨校交接"而不是"转学手续"。** 原校社工给新校社工或辅导员一通电话、一份一页纸的说明（谁在照顾他、什么会触发他、什么有效），比任何档案都管用。
3. **盯住三个易漏项**：法定文件的签署权在谁手上（医疗、教育、外出同意）；特殊教育或便利计划是否随转学延续；课外活动与毕业所需的隐性成本。
4. **不要每次闯祸都惊动照护者。** 亲属照护（尤其祖父母）常已在高负荷状态，频繁的负面通知会让家校关系迅速恶化，最后孩子失去唯一的稳定成人。校内能处理的事，在校内处理。

**监护变动**（离婚、监护权争议、亲属接管）要单独处理：孩子常被夹在中间，因"站队"而产生不忠感。可用的做法是给一个固定时段专门谈缺席的那位父母（每次十分钟，五分钟画或写，五分钟讲述），把它变成**正向出口**而不是审讯。

## 5. 校本小组工作

### 5.1 起组的六个前置条件

任何一项没满足，组会在第三、四次散掉。

1. **目的与目标能一句话说清。** 目的决定模型，也决定招谁。"提高社交技能"不是目的，"让这六名学生在午餐时段能加入一个三人以上的对话"才是。
2. **取得校方许可，且让校方参与定义。** 向辅导员、教师、行政说明，并**邀请他们参与"定成员与目的"**——参与了才会支持：帮选学生、帮说服教师放人、帮找场地。事后通报式的许可，等于没有许可。
3. **场地私密、整段时间不被打断。** 图书馆、食堂、礼堂都不合格；空置教室可以，但原教师要有别处可去。走廊尽头的谈话室若门不能关，也不算。
4. **家长书面同意，学生自选参与。** 先拿同意，再与学生逐个谈"兴趣与承诺程度"。**学生越觉得"是我自己选的"，越愿意留下**。同意书通篇写"学习技能"而不是"接受治疗"：写明学什么、几周、每次多久、具体技能清单。
5. **处理非自愿转介。** 行政常以小组"解决"旷课、愤怒管理、社交技能、物质使用。开组前必须与学生**和家长**分别单独会谈，说明目标与形式，让孩子有机会先把愤怒说出来——否则第一节小组就是他的申诉现场。
6. **保密框架书面化。** 说明单位政策、法规要求与社工的保密限制（自伤/伤人、虐待报告、记录被依法调取、家长要求查看自己孩子的信息），并**书面**给学生与家长。同时诚实写出：**社工无法保证组员一定保密**——这一句必须说，否则日后所有泄露都会算在你头上。

**避免标签化的四个机制**（比"注意措辞"有效得多）：
- 把入组叙述为**技能学习**而非治疗，同意书里列六项具体技能、每周一项；
- 用**自习课自选报名**（study hall sign-up）代替指派，"自我转介"既保证动机，也避免"被挑出来"；
- 用**全班规模的课堂小组**让参与正常化，此时请原班教师留室协助秩序；
- 对低龄儿童用"传话游戏"教保密，不讲抽象规则。

**结构与剂量**（这些参数比原则有用）：需要充分互动的治疗性小组要小，**五人**是"需要收集、交换、分析信息并做决定"这类任务的最优规模；限时小组的理想长度是**六次**，每次不超过 40 分钟（社交技能组 30 分钟足够）；规则由成员自己定五到六条；高中排课要**每周轮换时段**，避免同一门课反复缺课，并印一份时间表给每个学生与教师，前一天提醒；开组前逐个评估（个人需求未被照顾，成员就不会留）；第一次聚会就谈结案。

### 5.2 危机干预组 vs 预设组

| 维度 | 预设组（prearranged group） | 危机干预组（crisis intervention group） |
|---|---|---|
| 时间 | 可规划、可预评 | 事后尽快，几乎没有准备时间 |
| 成员 | 按目的筛选、年龄相近 | **直接受影响者**，尽量年龄匹配 |
| 规模 | 5–10 人；社交技能组宜偶数，便于配对演练 | **不超过 10 人**，保证每人都有说话时间 |
| 次数 | 六次为理想 | 多数只需 1–2 次 |
| 核心机制 | 技能教学＋角色扮演＋家庭作业＋跨系统强化 | 让成员**反复讲自己的版本**、释放情绪、听到同伴的相似反应而"正常化" |
| 结构 | 破冰—复习旧技能—教新技能—演练—布置作业 | 事实—想法—情绪—正常化—应对建议 |
| 失败形态 | 剂量不足、教师不强化、成员被动 | 变成事实追问会；有人被二次暴露；结束得太快没人接手 |

一条必须记住的教训：**没有杠杆的社工带不住群体。** 曾有一个八名情绪障碍学生的社交技能组，第一节桌下踢来踢去，第二节撤掉桌子围圈，仍有人在被辱骂后起身动手，带领者几乎被打到；直到请特教助理留室记录不当言行、学生处在层级系统里、扣分有真实后果，小组才运转起来。**社工在校园里的权力是借来的**，借的是教师的奖惩系统与课堂结构，不借就带不动。

### 5.3 破冰与活动设计原则

- **每次以破冰开始，多数五分钟够。** 破冰要"非威胁但强制"：可以允许一部分人不参与，但主体活动必须人人卷入。
- 破冰的功能有四：让人放松、忘掉自己、加入群体、发现共同点。四个可用活动：两个真相一个谎、边界突破（结对问答后向全组报告，可答可拒答）、名字加手势、抢位子类游戏。
- **物理布置要防冲突**：桌子要大到踢不到对方，椅子间距要够，出口不要被堵。
- **结构要可预期**：同一时间、同一地点、同一开场—复习—新技能—演练—作业的节奏。可预期本身就是治疗成分。
- **每次留出约十五分钟演练**，且"不许嘲笑"是演练有效的前提规则。没有演练的小组只是讲座。
- **活动不为热闹服务**：每个活动后面必须有加工（"刚才那轮，谁觉得不舒服？什么时候？"）。只做活动不做事后加工，是校本小组最常见的空转。

### 5.4 成效测量：校本可用的做法

不需要等标准化量表，先把可判定的东西写下来。

1. **以契约为准绳。** 开组时把目的、目标、契约写清，结束时"是否达成"就变成可判定的事，而不是感觉。
2. **学生自评。** 儿童与青少年是自己进步的最佳监控者——每周一次 1–10 评分加一句理由，比任何他评都稳定。
3. **承认部分达成。** 限时小组结束时，要帮学生识别"已经取得的进展"，而不是只清算未完成项；否则最后一次聚会会变成挫败体验。
4. **家长书面通报。** 结案发一份进度报告，列出当初设定的目标；长期小组每六周发一次简讯。这一动作同时在做家校关系。
5. **教师端迁移检查。** 把学到的技能明确告知教师，请教师在课堂上强化，社工做教师的后援。**没有迁移检查的小组，效果几乎一定留在小组室里。**
6. **必要时借外部量表**：儿童抑郁量表、青少年抑郁量表、儿童自我概念量表、行为评估系统、儿童行为清单一类工具，选年龄范围匹配、有常模、施测成本可承受的。量表是补充，不替代 1–5。

## 6. 创伤、暴力与丧失

### 6.1 创伤反应的分类与识别

**定义**：创伤性体验使个体的压力反应被异常长时间地激活。一个事件之所以是创伤性的，在于它具有威胁性、压倒性，且涉及自身或亲近者的生命。

**按年龄分层**

| 年龄层 | 典型表现 |
|---|---|
| 小学阶段 | 躯体主诉（头痛、腹痛）；对死亡与其他暴力事件的持续担忧；类抑郁表现（退缩、注意力差、睡眠与食欲改变）；退行（儿语、发脾气、遗尿）；愤怒与对抗 |
| 较大青少年 | 缺勤增加、成绩下降；对活动与朋友失去兴趣；反复咀嚼事件细节；解离与退缩，或过度警觉与坐立不安；男生可能谈报复、表达恨与怒；自责或扭曲现实；需要反复讲述以"重建现实" |

**按严重度看的十五项极端反应**：睡眠困难或不敢独处、进食障碍、抑郁、易惊、过度警觉、在环境中反复寻找"安全点"（进门先看出口）、渴望报复、冒险与冲动、暴力行为、退行、学校相关问题（缺勤、不及格）、悲观态度、物质使用、关系问题、解离。

**三个必须会的鉴别点**

1. **创伤症状与注意缺陷高度相似。** 误判为注意缺陷，孩子就得不到创伤治疗，还会被要求"更努力地集中"。
2. **创伤性悲伤 ≠ 一般丧亲。** 悲伤的核心是难过，创伤的核心是恐惧。严重受创的青少年可能需要先处理创伤体验的若干侧面，才可能进入哀悼——要求他"快点接受事实"是无效的。
3. **解离是隐匿的。** 白日梦、幻想、分心、假装、人格解体都可能是解离表现；孤立的孩子更可能"埋掉"创伤记忆，日后被触发。

**评估四要素**：焦虑与恐惧水平；是否符合创伤后应激障碍（post-traumatic stress disorder, PTSD）的症状群（再体验、回避与反应麻木、警觉增高、功能显著受损；症状持续一个月以上，事件与症状间隔六个月以上为延迟发作型）；既往丧失、创伤与危机经验；**此次创伤对这名学生的特定意义**（同一件事对不同孩子的重量完全不同）。

### 6.2 校本创伤干预的三级结构

| 层级 | 对象 | 做法 |
|---|---|---|
| **普遍（全班/全校）** | 所有学生，尤其同班同年级 | 课堂讲解悲伤与哀悼的常见阶段（各年龄段都可讲）；社工走访每间教室，说明正常与需要转介的反应，请师生自我转介；允许反复提问，每次给同样的诚实答案 |
| **靶向（小组）** | 直接受影响、年龄相近者 | **减压谈话**（defusing）：事件后很短时间内的一对一谈话，帮其讲出经历、获得客观支持，通常来自同伴；有效条件是尽早、有康复预期、简短朴素。**复盘**（debriefing）：五阶段——说明目的与规则 → 事实性重建 → 想法 → 情绪 → 指出彼此反应的相似性以正常化 → 给应对建议 |
| **个别（三级）** | 症状严重、需转介者 | 个别会谈加游戏与艺术媒介（黏土、彩纸、彩笔、小玩偶、布偶；"白纸、彩纸、彩笔是最有用的"）；涂鸦接龙式游戏破冰；把画揉掉或撕掉作为"丢掉这个念头"的象征动作；必要时转介临床机构 |

**稳定化计划的五要素**：识别需要支持的不同群体；压力管理活动；在葬礼、守夜、校内追思中的支持；识别需咨询者并转介；为不同"幸存者圈层"（同班、同队、同车、目击者、救援者）分别规划外展。

**团体复盘的操作规则**（适合高中生）：每组 4–6 人；保密；**强制出席**（否则最需要的人不会来）；每人发言或沉默的时间相等。五个处理性提问按序：①自我介绍加"你最初得知时在哪里，最初的感官印象是什么（看到、听到、触到、闻到什么）"；②"此后你有什么想法或反应"；③"对近期未来你最大的担忧是什么"；④"现在什么能让你感觉更安全"；⑤"过去遇到困难时什么帮过你，现在你能做什么帮自己"。带领者每节要小结，让成员看到"你不是一个人"；并明确说这只是起点，需要更多的人可以留下。**教师先走一遍流程，再带学生。**

**必须写清的争议**：不少精神卫生专家认为，没有证据表明集体复盘有效，也有人认为它会让某些人更糟。较稳妥的定位是——把复盘当作**筛查、支持与转介的入口**，而不是治疗；真正有支持的是"提供信息＋教授适当行为＋提供情绪支持"三者合起来，单纯教育性预防项目效果较差。因此复盘之后必须有追踪，用追踪判断谁需要进三级。

**助人者的耗损**：替代性创伤（vicarious traumatization）会打击教师与社工，无论专业角色如何都逃不掉。可行的安排是：给自己时间、谈自己的感受、请邻近学校的同行来提供咨询与支援。一个学校若只有一名社工，"同行支援"必须提前建好，不能等到出事再找。

### 6.3 校园危机响应流程

**通用五步**（适用于任何死亡事件）：
1. **确认与告知。** 由社工、行政（必要时加特教负责人）到教室分班次告知；先全班、后个别。告知前要确认信息准确，不要用"听说"。
2. **给信息。** 学生想知道发生了什么、逝者"作为一个人"是谁。含糊其辞会延长痛苦——"没有答案"本身会成为悲伤的一部分。可告知的范围内尽量具体，涉及隐私与调查的部分明确说"这部分我不能说，原因是什么"。
3. **给告别的方式。** 参加葬礼或追思、写信、画画、"想法页"（thought page：写下所有想法与感受，谈完可保留或撕掉以示告别）。
4. **尽快恢复结构与可预期性。** 立即补上正式教师；恢复常规课表与作业，但提醒教师"上课铃、突发噪音、消防演习都可能触发反应"。
5. **长期跟进。** 支持在最初几周最密集，之后社会支持自然衰减，而**衰减期正是最需要支持的时候**。要跨学年跟踪出勤与学业。

**三种情形分开写**

| 情形 | 额外的关键动作 | 最容易被做错的地方 |
|---|---|---|
| **同学死亡** | 向学生说明"你是健康的，大多数人会活到老"，以缓解"我也会死"的恐惧；对同班与自我认同为密友者优先；给同学一份"他回来后可以怎么回应"的脚本 | 把全班当成同质群体；忽略"其实我和他不熟"的孩子的内疚 |
| **教师死亡** | 不用"了结"（closure）这个词——对儿童而言"了结"往往不成立；成人期待几个月后放下，孩子可能因"忘记他"而内疚；补位教师不要急于推进课程，允许学生告诉她"你和原来那位有什么不同" | 急于"恢复正常教学"；把代课教师的权威问题当成纪律问题 |
| **自杀死亡** | 同时做两件事：帮知情者表达并处理悲伤；尽力降低模仿性自杀。排查是否存在同伴约定；聚焦同班与密友；回应聚焦"悲伤、震惊、丧失、恐惧、甚至愤怒" | 把逝者塑造成受害者或英雄；把自杀当成"不可谈的事"而全体沉默 |

**教职员死亡**另有一条：死后一个月是社工"在教师休息室与办公室出现"的关键窗口，同龄同事会出现"我也会突然死掉"的脆弱感。这一个月不做个案，只做在场。

### 6.4 自杀后响应的四条禁忌

四条，每条给一句"为什么"。

1. **不悼词化（do not eulogize）。** 为什么：把逝者塑造成被集体缅怀的对象，等于给"死能换来关注"这个等式付了第一笔钱；对正处在边缘的学生，这是最有吸引力的信息。
2. **不美化、不赋予意义。** 不说"他解脱了""他很勇敢""他为某件事而死"。为什么：青少年对"意义"的敏感远高于对"后果"的敏感；一旦自杀被读成一种有尊严的解决方式，模仿的风险就上升。
3. **不聚焦方法、地点与细节。** 不描述怎么做的、在哪里、用了什么。为什么：方法信息是可操作的——它把"想死"变成"知道怎么做"，而这两者的距离，往往就是一次冲动的距离。
4. **不持续暴露、不做永久纪念物。** 不在集会中反复播放事件影像，不设大规模永久纪念（可设一次性的、有时限的告别活动），对低龄儿童尤其避免反复接触事件画面。为什么：持续暴露会把一次事件固化成校园的长期身份，也会让"被记住"变成持续的诱因。

配套的三条操作：
- **允许说"我想他"。** 禁忌针对的是"美化死"，不是"否认想念"。禁止表达想念，会把悲伤转入地下。
- **给成人脚本。** 教师最怕说错话，于是选择不说。给一句可用的开场（"我今天来，是帮你们向某位同学道别"）比给一套原则有效。
- **长期未缓解的悲伤要追问。** 背后可能藏着秘密或罪恶感：可能并不喜欢逝者、可能吵过架、甚至说过"希望你死掉"。孩子怕被看成坏人而不敢说，社工的持续在场是让他开口的条件。

### 6.5 学校响应小组的组成与职责

多数地区设有跨校的流动危机小组，是"少数社工配多校区"这一结构的关键补丁。

| 角色 | 职责 |
|---|---|
| **召集人**（通常为行政） | 启动与结束响应；对外发言口径；与家庭、主管部门、媒体的接口；决定停课与复课 |
| **社工** | 需求快速评估；受影响圈层划分（谁必须第一时间见到人）；个别与小组干预；家庭联络；转介与追踪 |
| **心理师 / 辅导员** | 筛查与分类；班级告知的陪同；教师支持；三级个案 |
| **校护** | 躯体反应处置；药物与医疗信息；与医疗机构的接口 |
| **教师代表** | 课堂层面的信息传递；识别班上高危学生；维持日常结构 |
| **联络与后勤** | 通知家长；场地与时间安排；记录与档案；志愿者与外部资源的登记 |

**四条运作规则**：一是**先分级再分配**（按"直接目击—密友—同班—同校—家长"分圈层，不要平均用力）；二是**单一发言口径**（对外只有一个声音，避免信息冲突）；三是**写时间轴**（每个决定的时间与依据，事后复盘与法律上都用得上）；四是**给响应者留位置**（轮班、替补、事后减压，否则第二周就没人能工作）。

## 7. 家庭议题与心理健康服务

### 7.1 父母缺位的各种形态与影响差异

总纲要先说清：关键不只是"缺位"，而是缺位期间**照护的质量**。若有结构、一致、可预期的规则与至少一个稳定的成人，孩子仍能良好发展。

| 形态 | 影响的具体机制 | 介入要点 |
|---|---|---|
| **因工作长期不在**（长途运输、跨地务工、驻外） | 频繁搬迁与分离，难建立"根"，难维持承诺；留在家中的照护者负荷陡增 | 建"这类家庭的名册"（教师、辅导员、行政、注册人员都可提供线索）；以**家庭**为单位支持（常由祖辈照护，须让祖辈能进校门）；班级寄慰问包、定期视频时段 |
| **因虐待被带离** | 机构多遵循"家庭保全"，尽量不拆散；婴幼儿安置后两个月内可形成新的依恋；与照护者有正向情感联结、获身体亲近者，心理与学业适应更好 | 报告与案号管理；与儿童保护机构协同；训练其他教职工识别征象；把"探视与团聚"的时间表纳入学业安排 |
| **离婚与分居** | 孩子夹在中间，因"站队"产生不忠感；监护争议把冲突延长数年；经济骤降常伴随转学 | 给固定时段专门谈缺席的那位父母（十分钟：五分钟画或写，五分钟讲述）；把它变成正向出口；不在孩子面前评价任何一方 |
| **父母死亡** | 见 §6.3；教师须能识别"愤怒爆发"可能是抑郁与悲伤的表现 | 通知全体教师、教识别、给同学回应脚本、跨学年跟进；允许"我不太想被大家特别对待" |
| **父母入监** | 入监前常已暴露于物质、暴力、忽视与频繁的执法上门；照护多转给祖辈；累积风险的数量比单一风险更能预测结果 | 先问"入监前跟谁住、暴露了什么"；避免一有问题就打电话给可能施暴的家长（改为只与学生本人处理校内问题）；准备"如何向同学解释"的脚本 |
| **父母精神疾病** | 可导致无家可归、生活不稳、关系不一致与管教断裂；家长常无法稳定联系 | 校内提供一致性、稳定性与结构；确保午餐、接送、衣物；**排课与选教师是最有力的干预**——把孩子放进能给关怀的教师班里 |
| **无家可归** | 儿童占无家可归人口的相当比例，多数在十二岁以下；难以稳定上学、留级率高、发育迟缓比例高 | 到实际住处（汽车旅馆、临时安置点）做访问以把人连回学校；链接衣物、鞋、眼镜；确保早午餐；安排课后托育与辅导；做特殊教育与便利计划筛查；必要时安排交通 |
| **祖辈或亲属抚养** | 常见成因是物质使用、虐待忽视、离婚、父母病故或入监；这类儿童哮喘与呼吸道问题、免疫弱、饮食差、睡眠不足、注意缺陷比例更高 | 提供结构、可预期、一致与技能训练；排进"组织良好、管教一致"的教师班；个别咨询让其表达悲伤与愤怒；**不让每次闯祸都惊动祖辈**，以维持家校关系正向 |

### 7.2 物质滥用家庭的子女

**识别**

- 最隐蔽而首要的后果是**情感性缺位**：成瘾的照护者物理上可能在，情感上长期不在。极端情形下，子女被视作"获取物质的障碍"。
- 这类儿童更可能出现：攻击水平升高、品行问题、反社会行为、一种以上的心境问题（焦虑、抑郁）、以及自身的物质使用。
- 有研究提示，照护者滥用酒精或药物的儿童，被身体或性侵害的几率约为一般儿童的三倍，被忽视的几率约为四倍。
- 学校可见的表现非常普通：无法集中、疲倦想睡、行为问题、社交技能不足、缺勤、学业失败。**"普通"正是它被漏掉的原因。**
- 胎儿酒精谱系影响要认识：体型偏小、眼裂短、人中平坦、可能伴轻度智力障碍、注意短暂、多动、学习困难、协调差。它影响记忆（多步骤任务尤甚）、泛化能力与元认知，容易出现习得性无助——**"教了不会"不是不努力，是泛化失败**。

**介入（分层）**

1. **认知层**：用适龄语言解释"成瘾是一种病"，明确"这不是你的错"；帮其制定**安全计划**（照护者情绪不稳或有暴力时去哪里、找谁、打什么电话）。
2. **技能层**：问题解决与社交技能（这些孩子除暴力或回避之外，往往没有第三套应对脚本）、愤怒管理。可用五步口诀：停下并命名问题 → 想自己的感受与选项 → 选最安全、最能照顾自己的那个 → 找谁能帮 → 回看下次会不会这样做。
3. **结构化学校**：作业、考试、课堂活动都"不成为意外"。家里可能没有饭点、没有就寝时间、没有人能帮作业——**可预测性本身就是干预**。
4. **小组**：这类议题上小组往往比个别更有效。规模依年龄（越小越少），年龄跨度不超过一到两岁，预先决定性别构成（女孩的抑郁与低自尊更突出）；五条组规（一次一人说话、相互尊重、只用肯定性反馈不用贬损、人人有权跳过、这里说的话留在这里）。
5. **长程优于短程**：多数此类小组是短期的，而每周一次、贯穿整个学年（八九个月）的长程小组才能提供持续的支持与结构。
6. **两个高价值的具体设计**：**作业辅导小组**（这些孩子家里没人能帮作业，也没钱买材料；可申请弹性经费或向家长组织募款，组织志愿者辅导）；**请校警或学校资源警官进组**与孩子做普通朋友，以消解从家里习得的对警察的恐惧与过度警觉。

### 7.3 校内心理健康服务的层级

| 层级 | 对象 | 内容 | 谁在做 |
|---|---|---|---|
| **普遍层** | 全体学生 | 心理教育式干预（教育＋行为方法＋同伴支持三合一）；社交技能课程；反欺凌与校园氛围；新生与家长通讯；为孤立学生安排与校内某位成人的正向连接 | 全校成人，社工做设计与培训 |
| **靶向层** | 有早期迹象者 | 小组（社交技能、悲伤、父母离异、物质教育）；对服药学生与家庭的咨询与监测；导师制、作业俱乐部、签到签退 | 社工与辅导员 |
| **个别/三级层** | 功能显著受损者 | 个别咨询、危机干预、转介社区精神卫生、环绕式服务、住院后返校衔接 | 社工＋校外临床机构 |

一个结构性事实：住院与长期门诊资源被经费压缩之后，**学校实际上成了事实上的（de facto）精神卫生服务提供者**，因为它有服务儿童的法定职责与每天在场的位置。同时，学校社工个案量大，难以长期做深度咨询，因此**转介是常规而不是例外**。这一条要在服务开始就向家长说清，否则"你为什么不继续治"会在结案时变成投诉。

### 7.4 与社区机构的协同：信息共享与保密的边界

**三种具体接口**（比"加强合作"有用）：
1. **机构派人进校做初筛与资格认定。** 社工事先取得家长书面同意即可转介；机构人员在校内完成表格并预约首次评估，能消掉"成为机构案主前"的大部分等待。
2. **固定时段的校外临床门诊进校。** 例如每月一天由社区机构的精神科医生到学区，家长不必请假、不必自行挂号。很多家庭**不会自己去求助，但会接受"就在学校里的那次"**。
3. **校方作为信息枢纽。** 社工掌握学业表现、同伴关系、家庭情况，这些对校外治疗者有用；双方需要建立"开放而频繁的沟通、信任、适应性与相互尊重"的共同约定。

**保密的四条边界**

- **开始即告知**：服务开始时向学生、家庭与其他专业人员说明保密的限制与要求。开场没说清限度的保密承诺，后面必然变成失信。
- **书面同意才传信息**：向校外机构传信息、调阅记录，均须家长书面同意；同意书要写明"给谁、给什么、为什么、期限"。
- **小组场景的四个例外**要写进表单：自伤或伤人风险、虐待与忽视报告、记录被依法调取、家长要求查看自己孩子的信息。并诚实写明"无法保证组员不泄露"。
- **口译场景的额外风险**：使用口译时须事先向译员说明访谈目的，译员要能跨越语言与文化系统传达"内容与语气"；居留身份不稳定的家庭可能因怕被通报而要求不报告，此时要说清哪些必须报、哪些不会报，并说明后果由谁承担。

**一条判断**：协同的失败很少因为"机构不配合"，多数因为**没有人负责那一段接口**。若一个学生同时在学校、儿童福利、社区精神卫生、司法四个系统里，那么"谁在协调"必须有名有姓，否则四个系统各自合规，孩子仍然掉下去。

### 7.5 逻辑模型：怎么写、用来做什么

**用途**：在经费紧缩、资助方要求"证明服务的合理使用与预期结果"的环境里，逻辑模型是"澄清目标＋检验项目是否达到预期结果"的工具。对社工个人，它把"我的干预有效"从信念变成可检验的命题。

**三个要素**：**投入**（inputs，资源与人力）—**产出**（outputs，交付物：服务了多少人、开了几组、做了几次培训）—**结果**（outcomes，对案主、机构、项目、社区的影响），结果再分短期、中期、长期。

三者的区别是评审最常挑的错：**产出不是结果**。"开了六次小组"是产出；"六名成员中有四名在午餐时段主动加入过对话"是结果。

**六步构建法**

1. **陈述问题**：一句话，可观察、可计数。例：某生在课堂上每周爆发三到四次、全科不及格；背景是家中亲人去世、搬回与有暴力倾向的照护者同住、被安置进特殊教育且对此愤怒。
2. **分短期、中期、长期结果**：短期——每周爆发次数递减至零、每节课开始做作业、下课前交作业；中期——为愤怒找到正向出口、完成社区心理卫生的评估、处理丧亲的悲伤；长期——全科及格、加入一个社团、家庭愿意讨论现状并接受资源。
3. **写产出**：社工每周两次会谈（悲伤辅导、愤怒管理、社交技能、问题解决、推动参与课外活动）；与家长会谈并讨论转介；特教教师协助识别愤怒前兆、提供个别学业帮助。
4. **列投入**：学区资源（安置委员会定目标、计划以一学年为期、年末复审）、学生投入、家长投入、社区资源（心理卫生、戒瘾互助团体、就业服务）。
5. **标环境因素**：有受训人力的学区；社区是否有庇护所、戒瘾团体、劳动部门、家庭咨商；家庭资源（愿意努力的照护者、学生自己想改善、兄弟姐妹态度正向）。
6. **写假设**：校方假设（若提供特教与社工服务并促成课外活动参与，则愤怒行为可消除、学业可通过）；学生假设（若投入时间，行为与成绩改善；若参加活动，能交到朋友）；家庭假设（安置进特教对孩子有帮助；社工会帮到孩子与家庭）。

**评估逻辑**：从结果反推。结果未达成时，依次检查：投入够不够 → 产出完成了没有 → 短期结果是否真的构成中长期的地基 → 环境因素是否变化。量化与质性并用，并把这一轮检查写进下一轮设计——逻辑模型的价值在**循环**，不在那张纸。

### 7.6 资源匮乏与农村学校的替代做法

结构性障碍很具体：距离远、贫困集中、生均经费更低、社区不愿把钱花在社会项目上、留不住专业人力（课表超载、薪资无竞争力、缺少专业发展机会）。文化特征也具体：人口更同质、对多样性容忍度更低、价值更传统、期待"社区自己照顾自己人"。

**六条"以结构与关系换资源"的做法**：
1. **仍然靠跨专业团队**，而不是单打独斗。团队比任何个人更能弥补专业缺口，也更容易在人力流失时维持服务。
2. **工作对象是整个系统而非个别儿童。** 以家庭为中心的方案通常比以儿童为中心更有效：能维持儿童留在家里、避免家外安置。
3. **社工做社区网络的枢纽**：庇护性就业、心理卫生机构、集体之家、交通选项，都要亲自熟到能画出图。
4. **写方案、找经费、用实习生。** 若经费允许，可让实习生半职在其他机构工作，形成双向人力；这也是农村岗位最现实的扩员方式。
5. **用远程与区域共享**：跨校共享一名心理师或督导师、区域性的危机响应小组、线上督导。远程不能替代在场，但能补上"没有人可以商量"这一项。
6. **四条农村实践哲学**（可直接引用在工作记录里）：必须先尊重才能对质；对我们是失功能，对别人是现实；从优势上加比从弱点上减容易；永远不要低估韧性的力量。

## 8. 证据图景：什么有效、什么证据薄弱

这一节回答一个具体问题：**当有人说"学校社工有用/没用"时，这句话能说到多硬。**

### 8.1 干预类型与证据强度

| 干预类型 | 目标问题 | 证据强度 | 适用条件 | 备注 |
|---|---|---|---|---|
| 认知行为取向的校本小组（含家长训练） | 内化问题：焦虑、抑郁、自我概念、应对 | **中等**（合并效应约 0.4 量级） | 有筛选、剂量足（六次以上）、家长配合、带领者有训练 | 这是学校社工证据最好的一块；但单篇研究中只有少数达到统计显著，合并值受研究数量限制 |
| 社交技能／愤怒管理／行为管理小组 | 外化问题：攻击、品行、冲动、自控 | **小**（合并效应约 0.2 量级） | 必须叠加结构手段：层级系统、行为契约、FBA/BIP、全校行为框架、教师与家长作为主要干预者 | 不能靠"每周一次的小组"期待攻击行为显著下降；单篇显著者更少 |
| 知识与课程类（性教育、怀孕预防、虐待防治课程） | 知识、态度 | **大**（约 0.45–0.87），样本量大 | 课堂规模交付、课程完整、教师受训 | **效果好但离行为最远**：测的是知道，不是做到，更不是成绩与出勤 |
| 学业支持与学分补救 | 成绩、学分 | **中等但不稳固**（约 0.43–0.57，多数单篇未达显著） | 与课堂教学对齐、有持续监测 | 属"有希望但未稳固"，不能当作已确立的结论 |
| 出勤干预（含司法转介、家访） | 出勤、长期缺勤 | **弱**（多项研究中仅一项显著，其余接近零） | 必须同时处理家庭生计、交通、校园归属 | 出勤是最"远端"的结果，受家庭与结构因素支配最强；单纯司法施压常只让家庭更承压 |
| 同伴调解／冲突解决 | 冲突事件、关系修复 | **实践声誉远高于证据** | 结构化流程、成人督导、自愿参与 | 行政与教师普遍报告"很成功"，但严格的实证研究极少 |
| 危机后集体复盘 | 创伤症状、孤立感 | **争议**（"无证据"与"能减少孤立"并存） | 自愿或强制出席需谨慎设计；不作治疗用 | 应定位为筛查与转介入口，配后续追踪 |
| 全校层面（氛围、反欺凌、社交情绪课程） | 全校行为与氛围 | **框架背书强、实务研究少** | 全体成人执行、保真度高、持续两年以上 | 理论上收益最大，实际研究中此层几乎空缺 |
| 环绕式服务／多系统协同 | 复杂需求、家外安置 | **有支持但实施难** | 有服务协调员、有名有姓的接口人、家庭参与 | 效果取决于协调质量，而非服务数量 |
| 长程小组（成瘾家庭子女等） | 应对、内化问题、学校连接 | **实践支持、证据薄** | 每周一次、贯穿学年、稳定带领者 | 短程小组在这类议题上普遍剂量不足 |

### 8.2 三个必须说清的差别

**（1）内化问题与外化问题的效应量级不同，不能互相替代。** 以合并结果看，内化问题约在 **0.4 量级（中等效应）**，外化问题约在 **0.2 量级（小效应）**。这与既有文献一致：内化问题对心理社会干预更敏感；外化问题往往需要更强力、更聚焦、更多层的干预。实务含义不是"放弃外化问题"，而是——**不要用每周一次的小组去承诺攻击行为的显著下降**；要叠加结构性手段，并把教师与家长变成主要干预者。

**（2）出勤类干预的效果最弱。** 多项研究中只有一项达到显著，其余接近零。原因不神秘：出勤由家庭生计、交通、健康、校园归属、学业挫败共同决定，而社工能动的只是其中一小块。因此，**用出勤率单独评价学校社工，是不公平也不准确的指标**；更合适的近端指标是学校投入度（engagement）、座位学习时间、交作业率、被纪律转介的次数。

**（3）知识类干预"效果好但离行为最远"。** 性教育、怀孕预防、虐待防治课程的知识增长效应量很大（约 0.45–0.87），样本也大。但这类结果测的是"知道"，它与"做到"之间隔着态度、技能、机会与同伴规范。**把知识增长当作项目成功，是这一行最常见的自我安慰。** 若目标是行为，就必须测行为。

### 8.3 两类"实践声誉远高于证据"的做法

**（1）同伴调解（peer mediation）。** 行政、教师与社工普遍报告"成效卓著"，可真要拿研究出来，能引的往往只是"绝大多数调解达成了持久协议""不当行为转介减少了"这类**过程指标**，而不是冲突、攻击或氛围的对照比较。

> **实务建议**：继续做，但**不要把它当作减少暴力的主策略**。把它定位为"教一批学生一套冲突处理脚本，并给学校一个早期发现的渠道"；用过程指标（多少起冲突进入调解、协议维持多久、参与者满意度）如实汇报，不要把它们包装成"降低了欺凌率"。

**（2）危机后的集体疏导式晤谈（debriefing）。** 它在校园里几乎是危机响应的默认动作，但证据是分裂的：一派认为没有证据支持其预防创伤的作用，另一派认为它能减少孤立感、让人知道自己不是唯一一个反应异常的人。

> **实务建议**：把集体晤谈当作**筛查与转介的入口**，不是治疗。做，但做完必须有追踪：谁在两周后仍有症状、谁需要个别服务、谁需要临床转介。同时把"提供信息＋教适当行为＋给情绪支持"这三件事拆开做实——这三样才是有支持的部分。

### 8.4 RTI/MTSS：三层框架

**干预反应／多层支持系统**（Response to Intervention / Multi-Tiered System of Supports, RTI/MTSS）的四条原则：能力建设（不只直接服务儿童，还要提升教师与家长独立、可持续地实施实践的能力）；高质量、有研究支持的干预并按保真度实施；多层级组织；数据本位决策（用办公室纪律转介、筛查与进度监测判断谁对初级预防无反应）。

| 层级 | 服务对象 | 内容 | 社工的位置 |
|---|---|---|---|
| **第一层：普遍** | 全体学生；由校内**所有成人**实施 | 全校社交情绪课程、反欺凌、课堂管理训练、改善家长参与、改善学校氛围、课堂层面的暴力预防 | **以间接服务为主**：能力建设（让教师与家长成为主要干预者）、委员会参与、数据呈现、氛围改进。所需技能：多层框架知识、小组带领与共识建立、数据录入分析与呈现、协作与调解、参与策略 |
| **第二层：靶向** | 对第一层无反应者（通常约 15%–20%）；有早期迹象者 | 悲伤与离异小组、学业辅导、导师制、作业俱乐部、签到签退、家校沟通系统 | 小组带领加教师协作；仍以**间接支持**为主——帮教师更有效地与这批学生工作 |
| **第三层：密集个别** | 约 1%–5%；慢性、严重影响日常功能；常涉多个系统 | 行为干预计划（behavior intervention plan, BIP）、个案管理、持续咨询、特殊教育服务、家长支持、环绕式服务 | **直接服务＋家庭＋社区**。所需技能：家庭系统与社区服务知识、FBA/BIP/环绕式服务的专长 |

**三条必须记住的细节**：
1. **层级是连续谱，不是离散的三个盒子。** 第二层与第三层在实践中很难分开，硬分会制造"这个学生归谁"的无谓争论。
2. **初级预防越强，靶向需求越少。** 这是多层框架的内在逻辑，不是口号：第一层做得实，第二层的人数会下降。
3. **框架被广泛背书，实践并没有随之移动。** 调查显示，社工实际投入第一层的时间约占三成（另一轮调查降到约六分之一），而靶向与个别服务占六成上下；"与学生和教师一起会谈"这类最能连接日常教学的形式，常做的不足一成。也就是说——**框架不缺，缺的是把时间从第三层挪回第一层的授权与考核**。

**给实务的一句结论**：如果你的岗位只被允许做第三层，那么"学校社工有效吗"这个问题在你身上无法被回答，因为你从来没有机会做那些证据最好的事。

### 8.5 该领域研究的方法学短板

供选题与评审两用。六条，每条都指向一个可改进的动作。

1. **结果导向研究稀缺，且集中在少数模态。** 二十余年只筛出二十余项符合实验或准实验标准的实务研究，其中约四成是小组咨询、约两成是个别咨询；第一层（全校与能力建设）的干预研究几乎空缺。选题机会：第一层干预与能力建设的效果、保真度与成本研究。
2. **设计以准实验为主，随机化常被视为不现实。** 约三分之二是准实验、三分之一是真实验。评审时不要用随机对照单一标尺否定准实验，但必须检查**对照组的可比性、选择偏倚的处理、以及是否有基线等值检验**。
3. **测量与学校使命错位。** 多数研究只测心理结果或只测教育结果，同时测两者的很少；大量已发表研究中，达到严格标准且同时测心理与教育结果的只是少数。评审时要求作者说明"教育相关性"——出勤、成绩、纪律转介、投入度、座位学习时间、作业提交率。
4. **实施保真度严重缺失。** 使用手册的比例不到一半，**用录音或现场观察核查保真度的只有一成多**。没有保真度数据时，"无效"只能归因于实施，不能归因于模型；反之，"有效"也可能是实施之外的偶发因素。
5. **实施者资质混杂，效应量解释会失真。** 相当比例的研究由研究生实习生实施，其余由有经验的专业人员实施。实习生可能因经验不足低估效果，也可能因受督导更严、手册依从更高而高估效果；不报告实施者资质与督导强度的研究，效应量不可直接比较。
6. **不显著结果的处理会制造保守偏倚；异质性检验"不显著"常被误读。** 未报告统计量的不显著结果若被记为 0，合并值会偏低；而研究数量太少时，异质性检验本来就不容易显著，这**不等于"干预在不同人群中效果一致"**。评审时要查清"0"是真实估计还是填补值，也不要把"未能拒绝同质性"写成"效果普遍一致"。

调查类研究另有四条共性短板，评审时同样适用：无全国抽样框（样本即协会成员）、缺失数据严重、纯自报（只能测"做了什么"，不能测"做得怎样"）、横断设计（不能做因果推断）。此外，**概念操作化模糊**（只问"是否做"不问"如何做"，活动归类靠研究者判断，第二层与第三层难分）与**数字自洽性核查不足**（同一篇内百分比互相矛盾）也是常见问题——后者尤其适合当作"读表"训练。

## 9. 学校社工自查表

按五个环节，共二十项。每项只答"是/否/不适用"；**答"否"的项就是下一周的工作计划**，不要写成"待改进"。

**A. 位置与授权（1–4）**

- [ ] 1. 校内关键人（校长、教务、辅导员、校护、特教负责人）能说出我与辅导员的角色差别。
- [ ] 2. 我有一个私密、可关门、不被占用的谈话空间。
- [ ] 3. 我的服务目标中，至少有一项写成了学校认得的语言（出勤、成绩、课堂行为、关系）。
- [ ] 4. 我知道本校在特殊教育、便利计划、强制报告、记录调阅上的具体流程与责任人。

**B. 评估与计划（5–8）**

- [ ] 5. 我的每份介入计划都有可观察、可计数的目标，而不是"改善情绪"。
- [ ] 6. 我在介入前取得了基线（行为观察或频率记录），并在过程中持续记录。
- [ ] 7. 我的评估写了三栏：个体、情境、支持系统；并且认真考虑过"问题是否由学校自身制造"。
- [ ] 8. 计划里写明了谁在什么时候做什么，包括教师与家长的那部分。

**C. 直接服务（9–13）**

- [ ] 9. 服务开始时，我向学生与家长说明了保密的限度（含报告义务与记录调取）。
- [ ] 10. 我至少有固定时段做"与学生和教师一起会谈"，而不只是分别约谈。
- [ ] 11. 我带的每个小组都有书面同意、书面保密框架、以及第一次聚会就谈结案的记录。
- [ ] 12. 我的小组有演练环节，且技能在课堂上有教师强化。
- [ ] 13. 我的结案有正式动作，并在一个月内做过回访。

**D. 系统与协同（14–17）**

- [ ] 14. 我每周有不可被危机征用的时段，用于课堂、团队或全校层面的事。
- [ ] 15. 我能在转介后确认"真的接上了"（对方已联系、已评估、已排期）。
- [ ] 16. 对同时涉及三个以上系统的学生，协调人是有名有姓的。
- [ ] 17. 我给教师提供过可执行的东西（策略、清单、脚本），而不只是"评估结论"。

**E. 风险与自我维护（18–20）**

- [ ] 18. 我能在十分钟内说清本校的危机响应流程、响应小组组成与我自己的职责。
- [ ] 19. 我知道四条自杀后响应的禁忌，并能说出每一条的理由。
- [ ] 20. 我有一名可定期讨论个案的同行或督导；危机之后，我自己也被安排过支持。

**加两项可选的硬指标**（做了就写进年度报告，比"服务人次"有说服力）：
- [ ] 21. 本学年第一层（全校/课堂/教师培训/家长参与）的时间占比，我知道具体数字。
- [ ] 22. 本学年至少有一项干预有前后对比数据，且我愿意把没有效果的那项也写出来。

**最后一句**：这份文件里所有"应该"，都以一个前提成立——**你在这个学校有一个被承认的位置**。位置不在的时候，先做位置，不要先做技术。
