# 依据强度审计与使用边界

这份文件的作用是**让使用者知道哪些话可以放心用、哪些话必须自己回查**。它不装饰，也不辩解。

---

## 1. 本知识库的性质

本知识库是对一批社会工作专业文献（理论综论、伦理专论、个案/小组/社区实务教材、学校社会工作专著、学科导论，以及若干经验研究与综述类论文）的结构与要点整合编写。它**不是**原始研究的替代品，也**不是**任何单一文献的转述。

三条必须说清的限制：

1. **它是整合，不是汇编。** 文件中的框架、判据、动作序列经过重组与取舍，不保证与任何单一来源逐句对应。
2. **覆盖是不均匀的。** 有的主题域被精读到正文过半，有的只到框架层。差异见 §2。
3. **没有一条经验性数字是推算出来的。** 凡出现的量级（如效应量区间、比例），均取自原始材料并保留其原有口径；凡材料中没有的，不补。

## 2. 按主题域的覆盖强度

分级含义：

- **★★★ 充分**：该域的核心章节被通读，判据、步骤、失效条件均有直接依据，可直接用于教学与实务判断。
- **★★ 中等**：主体框架与关键技术有依据，但部分分支只到"结构与要点"层面，细节需回查。
- **★ 有限**：只有框架层或导论层依据，具体操作细节不足以支撑强断言。

| 主题域 | 强度 | 说明 |
|---|---|---|
| 理论的社会建构、理论评估判据、理论与实践连接 | ★★★ | 元理论部分被完整通读，是全场最扎实的一块 |
| 实践理论条目（二十余个取向） | ★★ | 每个取向的"核心主张—实务动作—失效条件"有依据；但各取向内部的流派分歧、最新进展未穷尽 |
| 价值与伦理、伦理困境决策 | ★★★ | 伦理专论七章通读，决策框架四套步骤完整 |
| 个案工作流程（接案至结案） | ★★★ | 流程、预估维度、目标判据、基线方法、结案类型均有完整依据 |
| 面谈技术（共情、跟随、面质、反效果清单） | ★★★ | 技术判据与话术结构完整；具体话术为本知识库按判据生成的示例，非原文照录 |
| 小组工作（类型学、动力、领导、阶段、任务组） | ★★★ | 主干充分；评估工具与部分量表细节只到类别层 |
| 社区实践（模型、评估、资产为本、倡导） | ★★ | 主干与倡导光谱充分；部分评估方法与组织技术的操作细节中等 |
| 学校社会工作 | ★★★ | 角色、生态—发展框架、分级干预、危机响应的依据最强；**法律条文部分只具一般性**（见 §3.1） |
| 人群与议题（贫困、青少年、复杂需求、家庭形态、创伤、成瘾） | ★★ | 机制与识别有依据；各议题的专门干预方案未穷尽，属于"够判断、不够照做" |
| 中国语境与治理 | ★★ | 机制分析有依据，但**经验基础是少数个案研究**，不可普遍化（见 §3.2） |
| 证据为本与研究评估 | ★★★ | 三要素、四重限定、有效性三问、设计类型判据完整 |
| 现象解读框架 | ★★ | 框架与工具为整合成果，其中"六要素""问题化五框架"的重组程度较高（见 §4） |
| 论文写作与评审量表 | ★★ | 七件套与六维量表为本知识库基于多种来源整合设计，不是任何单一标准的复制 |
| 案例与术语 | ★★ | 案例全部为虚构教学案例，不对应真实个案；术语定义为整合表述 |

## 3. 必须回查的四类内容

### 3.1 法律、政策与程序

**凡是涉及法定权力、报告义务、强制措施、资格与程序的内容，本知识库一律只给一般性表述。**

原因：这批材料中相当一部分的法律内容建立在特定国家（主要是北美与英国）的制度之上，条文编号、阈值、程序、责任主体都**不可移植**。

使用规则：

- 涉及"要不要报告""能不能强制""谁有权决定"时，**以使用者所在地现行法规与机构规程为准**；
- 本知识库中出现的"报告义务""同意能力""监护""强制入院"等，均为**类别名**，不指任何具体条文；
- 不要用本知识库的内容替代法律意见。

### 3.2 中国场域的经验性判断

中国部分的分析建立在**少量质性个案研究**之上（多为单一城市、单一机构类型、单一时点的案例研究）。它们的证据地位是**机制假说**，不是总体描述。

使用规则：

- 一律保留"有研究观察到""在某地实践中出现"的限定，**不得加"普遍""通常""我国社工都"**；
- 不得反向推断（不能因某地出现某机制，就推断别处不存在或一定存在）；
- 与本地实际不符时，**以本地为准**，并把差异本身当作有价值的观察；
- 不同研究中的"社工"可能根本不是同一所指（雇主、合同类型、法律身份不同），**跨材料并置时必须说明这一点**。

### 3.3 效应量与比例

本知识库中出现的少量量级（如某类干预在特定问题域上的效应量区间、某类服务的覆盖率），**只在原有口径内成立**：特定人群、特定问题、特定干预强度、特定测量方式。

使用规则：

- 不得去掉限定词单独引用；
- 不得把"在某问题域有效"改写为"普遍有效"；
- 不得把"统计显著"读成"值得推广"。

### 3.4 数字与事实的具体核对

已知需要回查的具体项（材料本身存在不确定性）：

| 类型 | 情况 | 处理 |
|---|---|---|
| 表格内部不一致 | 某份材料正文所述纳入研究数与表格逐行数不符 | 本知识库未采用该数字；引用相关结论时只用定性表述 |
| 百分比自相矛盾 | 某份调查报告的两类比例在逻辑上不可能并存 | 本知识库未采用该组数据 |
| 引文疑似截断 | 某处百分比合计不足 100%，疑为文本提取时截断 | 未采用 |
| 作者归属 | 某处的作者署名不完整 | 不影响内容判断，但引用时须核对 |

**这一节存在的意义**：一份不肯承认自己读到过矛盾材料的整合，是不可信的。以上四处都被实际发现，说明其余部分至少经过了同类核对。

## 4. 三处"重组程度较高"的内容（使用时须知情）

以下三处是本知识库的**整合与设计**，不是任何来源的直接陈述。它们好用，但要按"分析工具"而非"既有结论"来用。

| 内容 | 出处位置 | 重组的性质 |
|---|---|---|
| **四层系统与错配诊断** | `02-system-levels-and-router.md` | 层次划分在本学科有传统，但"五种错配症状""三种合法组合/两种非法组合""八问自测"是本知识库的设计 |
| **现象解读的六要素与五套问题化框架** | `14-analyzing-social-problems.md` | 六要素有明确来源；"五套问题化框架"及其盲点是并置多个来源后的归纳 |
| **六维百分制评审量表** | `16-review-rubric.md` | 维度与权重为本知识库设计；各维度的锚点描述是自定的评分参照，不是通行标准 |

**使用纪律**：引用这三处时，说"这是一个分析框架"，不要说"研究表明应当这样分"。它们的价值在于可用性，不在于权威性。

## 5. 三处已知的知识空缺

诚实列出，避免使用者误以为"文件里没写就是不存在"。

1. **专门领域的深度实务**：老年、残障、医务、司法、灾变、移民安置等方向的专门评估工具与干预方案，本批材料的覆盖不足以支撑操作级指导。涉及这些领域时，本知识库只能给通用框架与层次判断。
2. **临床与精神健康的具体处置**：诊断标准、用药、危机干预的医学处置，本知识库**不覆盖也不应覆盖**（见 §6）。
3. **量化方法与统计细节**：效应量计算、模型设定、缺失处理的技术细节，只到"如何读"的层面，不到"如何做"的层面。

## 6. 使用边界（不可越界）

| 不做 | 原因 |
|---|---|
| 不做临床诊断、不给用药建议 | 超出本知识库范围，且具风险 |
| 不出法律意见 | 法律内容只具一般性（§3.1） |
| 不替代危机处置流程 | 涉及自伤、伤人、虐待、家暴时，**先评估即时安全并按所在地法规履行报告义务**，本知识库只提供分析与沟通框架 |
| 不预测政策走向 | 结构性条件不等于趋势判断 |
| 不评价使用者本人 | 账算事，不算人 |

## 7. 依据强度自评的四级（供每一条结论自查）

| 级别 | 判据 | 可以说的话 |
|---|---|---|
| **A** | 多个独立来源一致，且有研究证据支持 | "在……条件下，这样做通常更有效" |
| **B** | 有明确来源与实务共识，但证据基础不均 | "主流做法是……；其局限在于……" |
| **C** | 单一来源或本知识库的整合判断 | "有一种做法是……；是否适用取决于……" |
| **D** | 推断、类比或教学示例 | "可以这样理解……"（须标明是示例） |

**一条提醒**：证据等级回答"可不可信"，**不回答"值不值得做"**。成本、可及性、公平这三关，没有一关是统计问题。
