# 实践理论条目：二十三种取向的主张、动作与失效条件

这份文件只回答一个问题：**手上这个案子，该用哪套东西；用错了会怎样。** 不梳理理论史，不比较谁更深刻，不给"综合运用"这类不承担后果的话。

**读法三条**

- 每条六栏，顺序固定：核心主张（问题从哪来、改变怎么发生）→ 实务动作（可照着做的顺序）→ 代表技术 → 最适合 → 失效条件 → 常见误用。
- **失效条件比适用条件重要。** 任何一条取向用过头都会造成伤害，而且伤害方式可预测：优势视角会掩盖剥夺，依恋会变成母亲问责，任务中心会把结构问题改成个人待办。
- 标题下的元数据行给四件事：层次、传统、证据强度、时间尺度。**跨层使用必须改写，不能照搬。**

**关于"证据强度"**：强／中／弱是对"这套东西能否稳定产生它宣称的结果"的粗略判断，不是对理论价值的裁决。弱的取向可能仍不可替代（权利被剥夺时，倡导往往是唯一能做的事）；强的取向可能完全不适用于眼前这个人。

## §0 选理论的流程

### 0.1 七步

按顺序走，**不要跳步**。跳步最常发生在第 1 步和第 2 步：直接跳到"我知道有个方法很好用"。

**第 1 步：定层次。**
这次要动哪一层——①个案与家庭／②小组／③社区与组织／④制度与政策。判据不是"我想做什么"，而是"你要改变的那个东西，谁有能力改变它"。孩子不上学，可能在四层都成立，但每次只能选一个介入点。

**第 2 步：定授权。**
案主能不能自己做主，分三档：**自愿且能决定**／**自愿但决定能力受限**（认知、年龄、精神状态、被胁迫）／**非自愿或有法定强制**（法院、儿童保护、强制治疗）。这一档决定了哪些取向根本不能用——强制情境下用纯非指导的人本取向，是把工作者自己的需要当成案主的需要。

**第 3 步：定时间。**
一次接触、六周、六个月、长期跟进。危机介入与寻解在"一次接触"里成立；心理动力与批判实践在"六个月以上"才谈得上。**时间不够时不要减量使用长程取向**——减量的长程取向是最糟的组合，只剩仪式感。

**第 4 步：定问题形态。**
急性还是长期？单一事件还是反复循环？卡在个人、关系、还是机构之间？这一步直接查下面的对照表。

**第 5 步：定改变载体。**
靠什么发生改变：谈话、任务、关系本身、共同活动、制度文件。载体错了，技术再好也落不了地——让一个不识字、居无定所的案主做思维记录，是载体错配，不是他动机不足。

**第 6 步：过机构筛。**
机构允许什么、督导能不能跟上、记录与考核容不容得下。完整的一套认知行为实践需要训练与督导，一般机构不具备；批判实践在政府购买的考核表里通常没有栏位。**机构不允许的，写进方案也只是纸面合规。**

**第 7 步：写一句边界。**
"我用它改什么、不改什么。"并定下 1 个主取向 + 最多 1 个辅取向。写不出这句话，说明还没选完。

### 0.2 四道前置筛（用来快速排除）

| 前置条件 | 若是这样 | 先排除 |
|---|---|---|
| 有即时人身风险 | 自杀、他伤、虐待、断药、无住所 | 一切以"理解""表达""成长"为主轴的取向；先做安全与保护 |
| 目标由第三方设定 | 法院、儿童保护、学校处分 | 纯非指导取向、纯赋权（会把工作者放在虚假的中立位置） |
| 时间在 6 次以内 | 转介、出院、一次咨询 | 长程洞见取向、结构改造取向（可以分析，但不能承诺结果） |
| 问题是十户人家同时遇到的 | 拆迁、污染、失业、学区 | 个案辅导作主干预（会把结构问题写成个人适应问题） |

### 0.3 问题形态 → 首选取向

| 问题形态 | 首选 | 并置 | 一开始别用 | 判据（一句话） |
|---|---|---|---|---|
| 急性危机（自杀风险、突发丧失、家暴刚发生） | 危机介入 | 任务中心（2–6 周后接手） | 心理动力洞见、叙事 | 先恢复稳态；任何"理解"都排在安全之后 |
| 长期依恋创伤（反复被抛弃、寄养辗转、亲密关系反复崩） | 依恋 | 优势、系统 | 认知行为单用 | 要改的是照顾环境，不是孩子对环境的反应 |
| 具体问题需限期解决（欠费、住房、出院安置、照顾安排） | 任务中心 | 倡导、个案管理 | 心理动力、批判 | 有可界定的结果，也有截止日 |
| 非自愿案主（法院、儿童保护、强制戒毒） | 动机式访谈 | 任务中心、寻解 | 人本非指导、纯赋权 | 目标被外力设定，但"做不做"仍在他手里 |
| 重复性消极思维（反刍、惊恐、回避、强迫） | 认知行为 | 正念取向、动机式访谈 | 叙事、批判（作主干预） | 有可辨识的触发—思维—行为链 |
| 家庭互动循环（同一冲突反复上演，换谁都一样） | 系统与复杂性 | 依恋、叙事 | 单独做"那个孩子" | 换成任何一个人，冲突照样发生 |
| 系统多机构纠缠（三个部门互相推、案主被来回转介） | 系统与复杂性 | 倡导、个案管理 | 认知行为、寻解 | 卡点在机构之间，不在案主身上 |
| 权利被剥夺（被拒服务、安置决定、待遇不公） | 社会正义与倡导 | 赋权、反压迫 | 人本、寻解 | 该给的东西没给，先谈感受是次序错 |
| 身份与意义危机（"我这辈子算什么"、污名内化） | 叙事 | 存在主义与灵性、人本 | 认知行为（作主干预）、任务中心 | 缺的是一个可讲述的版本，不是技能 |
| 慢性病／临终 | 存在主义与灵性 | 依恋、叙事（生命回顾） | 任务中心、认知行为目标化 | 目标不是解决问题，是让这段时间可承受 |
| 社区失序（拆迁、失业、环境风险、邻里崩解） | 宏观实践／社区工作 | 生态、社会发展 | 个案辅导（作主干预） | 十户人家同时遭遇同一件事 |
| 文化边缘化（移民、语言不通、被贴标签） | 多元文化敏感 | 反压迫、倡导 | 通用"文化食谱" | 误解发生在两套解释框架之间 |
| 原住民／少数群体（土地、语言、自决） | 原住民实践 | 反压迫、生态、叙事 | 单用文化能力训练 | 这是权力与自决问题，不是知识问题 |
| 愤怒与暴力（施暴者、失控风险） | 认知行为（含责任化程序） | 动机式访谈、系统 | 纯人本共情、纯赋权 | 先处理安全与责任，再谈理解 |

**读表提醒**：这张表给的是"第一顺位"，不是"唯一答案"。三件事会推翻它——案主明确拒绝（可接受性优先于疗效证据）、机构无授权（做了也不成立）、出现新的风险信号（安全优先于一切）。

## §1 心理动力关系实践（psychodynamic relational practice）

> 层次：①个案与家庭｜传统：社会凝聚｜证据强度：弱—中｜时间尺度：长程（数月—数年）

**核心主张**　人的问题既不在心里，也不在环境里，而在**关系**里生成、在关系里维持。早年关系留下的情感残余会被带进当下的每一段重要关系，包括与工作者的这一段。所以改变不必等"想通了"才发生——它可以在眼前这段关系里被演出来、被看见、再演一遍不一样的。

**实务动作**
1. **共建故事。** 按他的节奏与说话方式问"这件事从什么时候开始变成这样"，不要替他命名（不要一开口就说"这是丧失"）。你的第一个任务是把他的说法完整复述回去，而不是解释。
2. **把自己当线索。** 记录两栏：他怎么对待我（保持距离？求赞许？测试我会不会走？），我什么时候想保护他、什么时候生气、什么时候想快点结束。这些感受常是他让其他重要他人产生过的感受。
3. **提可被拒绝的假设。** "我猜……是不是这样，不对你改我。"用问句，不用判决句。诠释下得太早，案主会开始配合你，而不是探索自己。
4. **在关系里演练。** 请他把想对某人说的话先对你说一遍，或把某次冲突在会谈里重演一次，然后停下来看刚才发生了什么。
5. **修通。** 回到具体实例，一次一次地问："那次如果换成另一种反应，后面会怎么走？"不做一次总结性的领悟。
6. **设限与容纳。** 时间、频率、边界必须稳定——稳定本身是干预。同时用督导处理反移情，不把"我在被激起"带进记录当结论。

**代表技术**　反思性倾听与情感反映｜诠释｜关系演练（enactment）｜修通（working through）｜设限与容纳（containment）｜节制性自我表露（披露的任何关于自己的事都必须对案主有明确益处）

**最适合**　长期个案；情绪与关系困扰；反复的人际失败（总是被解雇、总是被离开）；临终与哀伤；住宿照顾中的治疗性环境。

**失效条件**
- 需要语言表达与自我审视能力。对短期、实务导向、非自愿案主，这套东西会退化成工作者的独白。
- 机制建立在不可直接观察的心智结构上，个案叙述再动人也不构成证据。**"讲得通"不是"是真的"。**
- 容易排除社会因素：失业被读成懒惰，成瘾被读成疾病，家暴被读成她选择了这样的伴侣。这是受害者责备最常见的入口。
- 洞见取向容易停在"他懂了"。懂了不等于改了，尤其在防御根深蒂固时，"理解"反而变成改变不可能的证明。
- 文化假设以中产、双亲、可反思的成长环境为常态。对不符合这个模板的家庭，它先判定其异常，再解释其异常。

**常见误用**　把"他在移情"当成解释一切的口袋——实际上只是工作者被冒犯了。

## §2 心理动力依恋实践（attachment-informed practice）

> 层次：①个案与家庭／②小组｜传统：社会凝聚｜证据强度：中｜时间尺度：中—长程

**核心主张**　人天生要靠近一个可依靠的人；靠近得到回应，才敢离开去探索。照顾关系反复失调，会固化成一套"别人会怎么回应我"的预期，在威胁情境下自动启动。改变的关键不是让当事人想通，而是提供一段可预测、且断裂能被修复的照顾关系。

**实务动作**
1. **评估照顾史，不评估症状清单。** 问的是"他难受时找谁、找到什么"，不是"他有什么问题"。儿童可用分离—重聚观察与故事补全，成人用依恋访谈。
2. **先判关系是否安全。** 如果照顾关系本身不安全，单独给儿童做治疗不但无效，还可能强化"我有病"的自我观——因为他回家仍要面对同一套回应。
3. **把照顾者当主要干预对象。** 提升敏感性、回应性、可预测性。这一条常被跳过，因为改大人比改孩子难。
4. **先满足情感需要，再处理行为困难。** 顺序反了必失败：一个还在确认"你会不会不要我"的孩子，学不会情绪管理技巧。
5. **修复断裂。** 每次冲突、失约、失控之后，必须有一次"回来谈"——依恋的核心不是从不破裂，而是破裂之后能修复。

**代表技术**　同频训练（匹配语速、音高、节奏、强度）｜"不知道的姿态"（不宣布你的解释，帮他自己猜别人怎么想）｜安全经验唤起（照片、音乐、旧物）｜游戏性—接纳—好奇—共情四态度｜容纳与互惠｜三层隐喻（地基＝安全基地，中层＝四态度，屋顶＝行为管理）

**最适合**　儿童保护与寄养／收养；照顾者指导；成人丧失与照顾关系；搬迁、入住院舍、离开寄养、换主要照顾者等转折期。

**失效条件**
- **婴儿决定论**：假定头几年定终身。实际上一段稳定的后期关系可以改写很多东西，这个假定会让人放弃成年案主。
- **母亲责备**：默认只需一位（通常是母亲的）照顾者。父亲、祖辈、社区网络在模型里常常缺席，出问题时却都由母亲承担。
- 被机构、法律与政治借去支撑确定性判断——"依恋受损"可以成为剥夺抚养权的理由，而研究撑不住那种确定性。
- 解释过宽：把所有问题都归到依恋，等于用一个概念解释一切，也就等于什么都没解释。
- 把"不安全"读成病态。跨文化研究中安全型占多数，不安全是相当大的少数群体，且常常是对不确定照顾的合理适应，不是缺陷。
- 忽视贫困、住房、工作强度对照顾能力的挤压，把结构性匮乏读成"敏感性不足"。

**常见误用**　用一次评估给母亲定性，此后所有资源都用来监督她，而不是用来给她一个能喘气的下午。

## §3 危机介入（crisis intervention）

> 层次：①个案与家庭｜传统：社会凝聚｜证据强度：中—弱｜时间尺度：极短（1–6 次／数周）

**核心主张**　危机不是事件，是"惯常办法失效"的状态。客观很小的事也能把人推进危机，因为决定性的变量是他如何知觉这件事。危机同时是危险与机会：旧办法已经垮了，新办法此刻最容易被学进去——这是它值得被单独当成一个取向的理由。

**实务动作**
1. **先在场，后评估。** 前十分钟不做量表、不问病史，只做三件事：说明你是谁、说明接下来会发生什么、让他把话说完。
2. **危机评估，含致命性。** 直接问："有没有想过不活了？""有没有想过怎么做？""现在手边有什么？"——绕开问法不会降低风险，只会降低你的信息量。
3. **辨识诱发事件与主要问题。** 区分"他报的那个事"与"真正卡住他的那个事"。主要议题常常不是诱发因素（吵架是导火索，断药和欠费才是结构）。
4. **处理情绪，不在情绪高点做计划。** 倾听、确认、允许宣泄。此时给方案，他会点头，然后不做。
5. **生成并比较替代方案。** 至少三个，其中包括"什么都不做，会怎样"。让他排序，不替他排序。
6. **形成行动计划。** 谁、何时、在哪里、做什么、做不到时打哪个电话。写到能被复述的程度。
7. **后续协议与转介。** 明确下一次接触的时间与方式。危机介入最常见的失败不是技术不足，是"危机过去了就结案"。

**代表技术**　积极倾听与情绪确认｜宣泄（ventilation）｜致命性评估｜短程问题解决｜支持网络动员｜灾后心理疏导｜热线与急症团队协作

**最适合**　自杀风险；性暴力；家暴；突发丧失；灾难与群体性事件；精神科急症；重大生命转折（离婚、失业、被驱逐）。

**失效条件**
- 过度强调内部情绪反应，忽略文化、家庭与制度性隔离。一个被安置在陌生城市的移民，问题可能不在"情绪"，在"没有一个人能替她签字"。
- 短程假设不适合长期失能、慢性危机或长期照顾。把慢性困境当急性危机处理，会周期性重复"救火—结案—再烧起来"。
- 对不承认你有权介入的人无效。此时该谈的是授权与法律依据，不是技术。
- 理论根源在精神医学，"社会"成分常被稀释成一个叫"社会支持"的条目。
- 七阶段做得太标准，会变成流水线：案主还没从第 2 阶段缓过来，工作者已经在推第 6 阶段。

**常见误用**　把所有难做的个案都写成"危机"，以换取机构资源与更快的响应。

## §4 任务中心实践（task-centred practice）

> 层次：①个案与家庭／②小组｜传统：社会凝聚｜证据强度：强｜时间尺度：短程（6–12 次）

**核心主张**　不问成因，只问"你要解决哪几件事、先做哪一件"。效果不来自洞察，来自三件事：聚焦案主自己排出的优先项、有限时间的承诺、一连串可完成的小任务带来的成功经验。问题是给定的，情绪问题常随任务完成而缓解。

**实务动作**
1. **授权。** 说清你能做什么、不能做什么、有没有法定义务、记录会去哪里。案主的知情同意是后面所有协议的前提。
2. **探索问题。** 听他讲完整的"问题故事"，越过转介单上的说法。转介单写"家庭关系紧张"，实际可能是"儿子不肯叫她"。
3. **聚焦。** 把纠缠的问题拆成 2–3 个可分别处理的，按机构与法律要求分别评估。拆不开就先不拆，但要说明为什么。
4. **细化目标。** 把"想好起来"变成分开的、具体的、可观察的目标："两周内能自己去一次菜市场"。
5. **设时限。** 一般 6–12 次，明确写出来。时限不是为了节约，是为了提升动机与让进展可评估。
6. **书面协议。** 载明授权、问题、目标、时限。用"协议"而不是"合同"——合同暗示平等，实际并不平等。
7. **循环执行。** 商定任务 → 执行 → 下次先回顾上次任务 → 再商定 → 直到结束与评估。回顾必须在前，否则会变成每周重新开始。

**代表技术**　问题排序｜目标具体化｜时限设定｜书面／口头协议｜任务分解与回顾｜标准化任务清单

**最适合**　有可界定结果的实务问题：欠费、就业、住房、出院安置、照顾安排、子女入学；资源紧、周转快的机构；偏好指导而非探索的案主。

**失效条件**
- 短期取向对长期照顾与慢性心理问题无效。用 8 次任务中心处理十年的创伤，结果是"任务完成了，人没变"。
- "问题"由谁定义没解决。结构化会把结构问题改写成个人任务：找不到工作变成"修改简历""每天投五份"。
- 契约掩盖权力不平等。官方角色与专业地位带来隐性权力，改称"协议"并不解决被施压的问题——尤其当拒绝签协议的后果是失去服务资格。
- 可能成为对严重社会问题的最小回应。用"已完成 N 个任务"掩盖资源不足与政治意志缺失。
- 概念简单但极难教好。它要求极强的聚焦与提问能力，训练成本被系统性低估。

**常见误用**　把服务指标拆成任务清单发给案主签，然后称之为"案主参与"。

## §5 认知行为实践（cognitive behavioural practice, CBT）

> 层次：①个案与家庭／②小组｜传统：社会凝聚｜证据强度：强（适用条件严格）｜时间尺度：短—中程（8–20 次）

**核心主张**　人对生活可以做理性的管理；问题行为与问题思维可以被界定、测量、改变。成因在"学习"：刺激与反应的联结、行为之后跟着什么后果、以及被当成事实的信念与自动思维。改变靠可检验的练习，不靠领悟。

**实务动作**
1. **个案概念化。** 拿最近一次发作拆四栏：当时脑子里闪过什么词或画面／什么情绪（一个词）／做了什么或没做什么／身体什么反应。
2. **找四类因素。** 触发因素、调节因素、易感因素、维持因素。维持因素最关键——它解释为什么问题到今天还在。
3. **与案主商定"工作性概念化"。** 说清"这是假设，可能是错的，我们一起检验"。不商定就上技术，是在替案主决定他有什么问题。
4. **建基线。** 事件记录、0–10 评分、频次。没有基线就没有进展，只有印象。
5. **排序干预。** 抑郁与回避优先行为激活／暴露，惊恐优先内感受暴露，强迫优先反应阻止，信念层工作放后面。
6. **固定会谈结构。** 议程 → 上次作业回顾 → 本次主题 → 新作业 → 反馈。结构本身就是干预。
7. **让他成为自己的工作者。** 每次结束前问"如果下次又这样，你会怎么处理"，而不是"你记住了吗"。

**代表技术**　系统脱敏｜暴露（含实景）｜正强化与消退｜示范｜自信训练／社交技能训练｜认知重构｜思维记录｜行为实验｜放松与正念｜DBT 与 ACT 的部分模块

**最适合**　抑郁、焦虑、社交恐惧、创伤后应激、强迫；技能训练（含学习障碍者）；成瘾与司法场域中目标明确的改变。

**失效条件**
- 完整使用需要训练与督导，一般机构不具备。半套 CBT 常只剩"换个想法"，比不做更伤人。
- 假定问题主要在认知行为层。遇到贫困、歧视、照护赤字，它会变成让个人替制度付账。
- 只认一类证据，挤压其他知识。"有效"被窄化为"可随机对照检验"，于是不可标准化的东西（关系、陪伴、倡导）系统性贬值。
- 文化上把一套特定的"合理思维"当标准。集体取向、宿命解释、宗教归因会被当成"认知扭曲"。
- 行为操控风险：非自愿案主、住宿机构中的奖惩滥用、以"行为契约"为名的剥夺。

**常见误用**　把"认知重构"做成"你想开点"，然后记录为已完成一次干预。

## §6 动机式访谈（motivational interviewing, MI）

> 层次：①个案与家庭｜传统：社会凝聚｜证据强度：中（小到中效果）｜时间尺度：短—中程（1–8 次）

**核心主张**　改变是分阶段的，不是一次顿悟。人卡在"又想改又不想改"的矛盾里，越被说服越辩护——这是逆反，不是愚蠢。所以工作者的任务不是给理由，而是把案主自己已经说过的理由放大：**改变的话从谁嘴里说出来，决定了它会不会被执行。**

**实务动作**
1. **先立精神，再上技术。** 四要素：伙伴（partnership）、接纳、慈悲、唤起（evocation）。接纳含四件事：尊重其内在价值与潜能、准确共情、支持自主、肯定。
2. **守住平衡位（equipoise）。** 不把自己的目标偷偷换上去。做不到这一条，后面全是表演。
3. **按四原则推进。** 表达共情 → 发展落差（理想与现状之间）→ 随阻力转（不正面冲突）→ 支持自我效能。
4. **全程 OARS。** 开放式提问、肯定、反映（把矛盾原样反映回去，不加评论）、摘要（把散落的改变谈话连起来）。
5. **判断阶段。** 前意向／意向／准备／行动／维持—复发。阶段不对，技术全错：对前意向的人讲行动计划，等于替他关上门。
6. **记两个比例。** 改变谈话与维持谈话的时长比；提问与反映的比例。作为督导指标，比"感觉谈得不错"可靠。

**代表技术**　OARS｜价值卡片排序（把价值卡分堆，比较"现状"与"理想"，引出落差）｜改变谈话的引出与强化｜双面反映｜去框架化（reframing）

**最适合**　成瘾（原始场域）；司法与儿童保护中的非自愿案主；青少年；公共健康（戒烟、慢病管理）；亲密关系暴力；职业康复；无家可归者。

**失效条件**
- 效果是小到中等，且最大效果出现在"有详细手册＋密切督导"时。没有这两样，它退化成"态度很好的聊天"。
- 对比效应明显：在原本就用强硬对抗法的服务里显得突出，在本来就温和的服务里差别不大。
- 把改变责任放在个人身上，不问造成问题的社会条件。贫穷、不平等、健康不良都被留在括号外。
- 协作模型与强制机构的目标天然冲突。可能出现"配合期间顺从、监督结束就复原"，而记录上写着"动机已建立"。
- 理论连贯性受质疑：它描述改变，但不解释改变。
- 前意向阶段需要长期偶发接触，很多机构的结案制度等不到那一刻。
- 缺少非西方与集体主义情境下"家庭／社群共同参与改变"的研究，直接移植会漏掉真正的决策单位。

**常见误用**　把"不评判"做成"不表态"——案主施暴也不指出，称之为"跟随案主"。

## §7 系统、复杂性与混沌（systems practice, complexity and chaos）

> 层次：①个案与家庭／③社区与组织｜传统：社会凝聚（借用了变迁语汇）｜证据强度：弱（缺清晰处方）｜时间尺度：视层而定

**核心主张**　一个人的行为是他在网络中的位置造成的。因果是循环的：A 的反应是 B 的原因，也是 B 的结果。干预点在联结、边界与规则上，不在任何单个人身上。系统被推动后会回到原样，所以要看"谁和谁的关系变了"，不看"谁改了"。

**实务动作**
1. **先定焦点系统。** 个人、家庭、机构还是社区？画出它的边界，以及它上面的超系统、下面的次系统。定不下来就还没有开始工作。
2. **用四系统定位。** 改变主体系统（我与我的机构）、案主系统（谁在寻求帮助、谁参与，含"潜在案主"）、目标系统（谁需要变）、行动系统（谁和我一起干）。再加专业系统：机构规章、法律、专业社群。
3. **辨三类助人系统。** 非正式／自然系统（家人、邻居、同事、门卫）、正式系统（社区团体、工会、互助组）、社会系统（医院、学校、民政）。多数方案只用了第三类，所以一撤就塌。
4. **选干预点。** 改变联结（把两个不相干的人接上）、引入资源、改善网络密度、改机构规则。四个里面挑一个，不要同时动四个。
5. **定"最小充分干预"。** 动一个点能带动几个关系，才值得动。系统的软肋是"什么都连着"，所以必须自己设停手线。

**代表技术**　生态图／网络图｜循环提问｜多专业个案会议｜生活模型（契合、适应、生活压力源、生命历程）｜社区资源动员｜边界与规则重构

**最适合**　家庭冲突与亲子循环；多机构纠缠的复杂个案；社区层面的健康与社会问题；机构层面的服务设计。

**失效条件**
- 什么都能解释，因此给不出处方。像推网袋里的球：全都动了，看起来没变。
- "适应"预设现状。容易滑成"你要接受不义的现实"，或过度适应他人的期待。
- 整体主义导致过度评估，超出案主理解与真正同意的范围。把焦点从"孩子"移到"全家互动"，很多家庭不接受——他们要的是"帮我管住他"。
- 把自然环境当无生命背景。物理环境（住房、污染、通勤、气候）在模型里常只剩一个格子。
- 偏重问题与适应不良，少谈优势与资源。
- 无法理论化结构变迁：它能描述系统如何维持，不能说明系统如何被推翻。

**常见误用**　画一张漂亮的生态图放进档案，然后照旧只做个人辅导。

## §8 宏观实践／社区工作（macro practice / community work）

> 层次：③社区与组织｜传统：社会凝聚／赋权之间｜证据强度：弱—中（实践总结为主）｜时间尺度：长程（年）

**核心主张**　问题不在个人适应，而在"谁能进入决策"。人被排除在影响自己的决定之外，才会显得无能。改变靠聚集：让共享同一处境的分散个体，变成能提出要求的一群人。

**实务动作**
1. **界定社区与代表性。** 这个"社区"是地域还是共享议题的人群？谁被代表、谁没来、谁替谁说话。
2. **从成员自己界定的议题出发。** 不是你或资助方列的优先项。若必须做资助方的议题，先明说这是条件，再谈怎么在里面留出成员的空间。
3. **选层级。** 个案倡议（为具体的人争取）／议题倡议（针对某项政策、设施、决定）／系统性改变（组织与程序）。
4. **选场域。** 机构内还是机构外。机构内成本低、天花板也低；机构外空间大、风险也大。
5. **建组织。** 会议、核心小组、联盟、对外发言人。没有组织化，一次胜利就是终点。
6. **追问"发展"由谁定义。** 就业项目与环保诉求可能正相反；"更新"对房东是收益，对租户是迁离。
7. **设计交接。** 社区工作最容易被项目周期切断。撤出前要留下能自己开会、自己写申请的一群人。

**代表技术**　居民会议与参与式规划｜自助与互助团体｜志愿项目｜社区组织与联盟｜公众教育｜政策倡议｜社会创业｜资产地图

**最适合**　失业与就业边缘群体；移民与难民网络；邻里衰败与住房更新；族裔冲突；环境议题（反公路、反机场扩建）；特定职业群体的健康与安全；孤立社群。

**失效条件**
- **家长主义。** 机构想控制甚至设定社区的目标与方法。"能力建设"因此可能变成侮辱——它预设外人知道社区该达成什么。
- 社区内部利益并不一致，代表性无法保证。最响的那个人常不是最多人的那个。
- "有魄力"与"替社区做主"只差一步；"鼓励参与"与"逃避专业责任"也只差一步。
- 被就业政策收编后，重心从赋权转为督促失业者接受不利条件。
- 时间尺度与个案工作冲突。同一批人既在做社区组织又在做危机个案时，个案永远赢。

**常见误用**　开三场居民议事会、拍照存档、写进结项报告，议题仍是机构选定的那个。

## §9 社会发展（social development）

> 层次：③社区与组织／④制度与政策｜传统：社会凝聚／赋权（双重）｜证据强度：弱｜时间尺度：长程（年）

**核心主张**　在增长优先的社会里，社会进步必须被嵌进经济项目，而不是另设一套福利去补救。贫困不是个人缺陷，是资源分配与历史结构（含殖民遗留）的结果。改变是渐进的、制度性的、以社区为单位的。

**实务动作**
1. **用后殖民视角看成因。** 土地、语言、行政边界、产业布局如何被历史塑造。不写这一段，后面的项目设计一定错位。
2. **把社会目标写进经济项目。** 合作社、微型信贷、就业与技能、住房与基础设施——而不是做完经济项目再补社会服务。
3. **优先贫穷与社会排除。** 明确谁被排除：无地者、迁移者、残障者、女性户主家庭。
4. **建立伙伴关系并写清谁主导。** 地方政府、社会组织、社区组织三方，主导权与收益分配要落在纸上。
5. **事先约定"发展"的定义权与收益分配。** 谁评估成功、按什么指标、收益归谁。这一条不写，项目越成功，本地人越边缘。

**代表技术**　能力建设｜社会资本培育｜合作社与集体经济安排｜社区组织与倡导｜社会创业｜灾后生计恢复

**最适合**　资源匮乏地区的社区发展；贫穷与社会排除；灾后重建；农村与原住民社区。

**失效条件**
- 定义上就把它锁进"接受现有秩序"：渐进改良回避结构性再分配。
- 容易被政府当作社会供给的温和补充，用来替代权利主张。
- 理论多由实践总结而成，跨国迁移时需大幅改写；直接移植会变成一套不接地气的项目模板。
- "发展"话语本身可能压过当地人的定义，尤其在资助方掌握评估权时。

**常见误用**　把"社会发展"做成一次技能培训班加一份结项报告。

## §10 社会教育学（social pedagogy）

> 层次：②小组／③社区与组织｜传统：社会凝聚／赋权｜证据强度：弱（价值清晰、技术薄弱）｜时间尺度：长程（日常）

**核心主张**　社会工作本质上是教育性的：人通过共同生活、日常场景与关系而成长，而不是通过每周一次的治疗会谈。工作者的身份是"一起生活的人"，不是"处理问题的人"。

**实务动作**
1. **把日常场景当干预载体。** 吃饭、游戏、劳动、节庆、就寝、打扫。干预不在活动里，在活动怎么被组织。
2. **以共同生活者身份进入。** 不做诊断式定位，不穿"专家"的外壳。这一条决定了后面所有关系质量。
3. **设计集体性活动而非个别治疗。** 让成长发生在同伴之间，而不是只在工作者与某个孩子之间。
4. **用生活世界取向决定权力平衡。** 谁定规则、谁能说不、谁的空间被尊重。规则若全由成人定，教育性就变成了管理性。
5. **把"尊重人的尊严"落到实处。** 落到"尊重这个地方"与"尊重这里人与人之间的联结"——不是抽象宣言。

**代表技术**　住宿照顾的日常结构化｜冒险教育｜艺术、体育、手作｜小组共同活动｜节庆与仪式｜青年工作中的同伴项目

**最适合**　儿童与青少年住宿照顾；青年工作；社区教育；残障与精神健康者的日间服务。

**失效条件**
- 在不少国家它是独立专业（独立训练体系与行业协会），硬并入社会工作会两边都不专业。
- 价值论述清楚但技术处方薄弱。遇上需要具体方法的高风险个案就哑火。
- "教育"目标可能与自决冲突：我们认为他该学的东西，他并不想学。
- 集体取向在个体化考核下最先被砍——它产出的东西（日常氛围、关系质量）最难写进表格。

**常见误用**　把"一起做活动"当理论落地。活动做完了，没人说得清他学到了什么。

## §11 优势视角（strengths perspective）

> 层次：①个案与家庭／③社区与组织｜传统：赋权｜证据强度：弱｜时间尺度：不定（多为中长程）

**核心主张**　人即使带着障碍也能学习、成长、改变；每个环境里都有资源，只是没被清点。问题不是人的属性，是人与环境之间的不匹配。改变靠放大已有的能力与资源，让"缺陷"在生活叙述中的比重下降。

**实务动作**
1. **用他自己的语言开场。** "你是怎么撑到今天的"比"你有什么困难"更能打开局面，也更能暴露真实资源。
2. **做优势评估，不做缺陷清单。** 五类：能力与技能、关系与网络、承诺与价值、物质资源、希望与期待。
3. **把社区资源纳入计划。** 谁、在哪、怎么接触、需要谁引荐。资源不写具体，就等于没找。
4. **共订目标，案主是导演。** 你提供选项与后果，他做选择。这不是客气话——导演选错，片子就是他的。
5. **同时处理环境中的污名、边缘化与劣势。** 优势视角不等于不碰环境；不碰环境，它就只是安慰。
6. **记录两栏。** "可动员的优势"与"被结构堵住的优势"。第二栏不写，优势视角就变成了让案主自己想办法。

**代表技术**　优势清单／优势评估｜社区资源盘点｜同伴支持｜公民身份与权利倡导｜希望与韧性工作

**最适合**　长期服务使用者（精神健康、复元取向）；儿童与家庭；残障；社区发展；可作为几乎任何取向的底色。

**失效条件**
- 正面取向可能不承认问题的真实性与严重性。案主会觉得"不现实""不被尊重"——他明明是来谈被打的事。
- 机构有管理行为的社会授权（儿童保护、司法）。一味谈正向与这一职责直接冲突，几起广受关注的儿童死亡个案都暴露了这个裂缝。
- **最危险的是被新自由主义收编**：用"优势"话语把照顾责任推回本已匮乏的家庭与社区，然后说"你们自己有能力"。
- 实证支持弱。它在个案管理与受暴妇女的人际实务中有一些证据，但远不如它的话语流行度。
- 容易空泛，缺少精确。优势清单人人会填，填完不知道下一步做什么。

**常见误用**　把"你有很多优势"当结论，替代了"你缺什么、谁该给"。

## §12 寻解实践（solution-focused practice）

> 层次：①个案与家庭／②小组｜传统：赋权｜证据强度：弱—中｜时间尺度：极短（1–5 次）

**核心主张**　谈问题的方式决定问题如何影响人。所以不必先弄清成因，先描述"你要的明天长什么样"，再找出已经发生过的例外。改变发生在会谈当下，不在两次会谈之间。

**实务动作**
三阶段循环使用：
1. **起点：从他偏好的终点开始。** "你怎么知道它好了？那天早上会有什么不一样？谁会先注意到？"目标必须具体到能被看见。
2. **谈"什么变好了"。** 用各种问法评估朝目标的进展，包括很小的进展。不要问"还有问题吗"。
3. **细说进展。** 谁做了什么、什么时候、怎么做到的、下一次怎么再来一遍。细节是这套方法的全部力量所在。

提问纪律：用他的词；用复数逼出第二个答案（"还有什么？"）；把焦点放到机构之外的生活；一种问法无效就换；从一般到具体；面对长期困境问"你是怎么熬过来的"。

**代表技术**　奇迹提问｜时间机器提问｜结果提问（"三个月后在街上遇到你，我会看到什么"）｜后续提问（"奇迹开始发生的第一小部分是什么"）｜关系提问（"谁会第一个注意到"）｜量表（0–10）｜例外提问｜应对提问｜肯定与赞美

**最适合**　儿童与家庭；学校；精神健康；受暴妇女；物质滥用；非自愿案主（从他半心半意的接受里接过议程）。

**失效条件**
- 语言干预撼动不了严重而持续的社会问题：贫穷、暴力、结构性排除。忙碌机构也没有时间做治疗式对话。
- 在儿童保护等高风险场域，若不同时置于风险评估框架内，会漏掉安全议题。这是它最严重的失败模式。
- "总是转向正向"会让案主觉得不被尊重，尤其在他刚讲完一件很痛的事之后。
- 目标模糊时，技术只剩花招。奇迹提问被当成开场白，是这套方法最常见的死法。

**常见误用**　第一次会谈就问奇迹提问，案主还在讲昨天被打的事。

## §13 叙事实践（narrative practice）

> 层次：①个案与家庭／②小组｜传统：赋权｜证据强度：弱（质性多、效果研究少）｜时间尺度：中程

**核心主张**　人靠把事件编成有时间、有主题的故事来理解自己。被一个问题故事垄断，人就只剩那一个身份。改变靠重写：把问题外化、把被忽略的片段接回去、把该在场的人重新请进故事。

**实务动作**
六阶段：
1. **界定问题。** 用他的原话，先不解释。解释权先交出去。
2. **外化。** 给问题命名，把它从人身上移到人与问题的关系上："这个'没用的感觉'什么时候来得最凶？"
3. **绘制影响。** 问题怎么影响生活、谁在支持它、谁在反对它、它在哪些场合弱。
4. **找独特结果，重写替代故事。** 找那些"问题本该出现却没出现"的时刻，把它们的来龙去脉说厚。
5. **重成员。** 谁该被请进新故事、谁该被请出去（包括已故的人）。
6. **维持。** 让新故事在日常关系里有支撑：见证人、信件、仪式、下一次怎么被复述。

姿态：贴住他的用词差异，跟随他的反馈，不心理化，不套假设。有时目标不是改变人，是帮他接纳自己。

**代表技术**　外化对话｜问题影响地图｜独特结果／例外｜见证小组｜治疗性信件与文件｜生命回顾｜跨时间叙事

**最适合**　亲密关系与家庭冲突；哀伤与丧失；精神疾病污名；残障；被寄养／收养者的生命史拼接；原住民与强文化认同社群；老年生命回顾。

**失效条件**
- 过于个体主义：只改个人故事，不碰社会冲突与不平等。压迫被重写成"另一种叙述"，处境没变。
- 过于表达性：重在理解与表达，不告诉人该做什么。实务上常需要另一套方法接手，而很多机构没有第二套。
- 可能被机构当成"讲故事"，回避权力与资源问题。
- **力量是双向的**：一个错误的故事被不断用新信息补强，最后可以把一个无辜家庭拆散。外化与重写既能解放人，也能把一个人锁死在一个更精致的指控里。

**常见误用**　把"外化"做成"这不是你的错，是社会不好"，然后没有下一步。

## §14 人本与以人为中心实践（humanistic / person-centred practice）

> 层次：①个案与家庭／②小组｜传统：赋权｜证据强度：中（关系因素强、技术效果弱）｜时间尺度：不定

**核心主张**　人有自我实现的倾向，只要关系条件对，他自己会往前走。问题来自"被有条件地接纳"：为了得到认可，人把别人的评价当成自己的真相，于是远离了自己的体验。改变靠三个关系条件——准确共情、真诚一致、无条件积极关注。

**实务动作**
1. **双重问责。** 对社会授权（政策、法律、雇佣责任）负责，同时对案主、家庭、社区负人际问责（以知情同意与慈悲落实）。这两条会冲突，冲突时要说明，不要假装没有。
2. **以平等为操作原则。** 把对方的身份当与自己同样的人——不是姿态，是具体的：不打断、不替他总结、不用术语。
3. **非指导、非评判、积极倾听。** 反映情感，不解释成因。解释会让对话变成你的推理展示。
4. **停在此时此地。** "你现在说这句话的时候，是什么感觉"比"你童年发生了什么"更有效。
5. **避免诊断与分类。** 但遇到风险议题要临时切换到保护框架，并说明为什么切换——不说明，就是不真诚。

**代表技术**　积极倾听｜情感反映｜共情性回应｜无条件积极关注｜非指导式会谈｜人本式小组｜表达性艺术与创造性活动

**最适合**　几乎所有关系的建立阶段；个人成长与意义危机；辅导与咨询；小组工作。

**失效条件**
- 内在矛盾：它以人的理性为基础，本可支撑实证取向，却被实证取向视为模糊、近乎神秘。两边都不认它。
- 个人信念体系该不该进入专业活动，边界不清。灵性与宗教尤其敏感。
- 缺乏清晰目标与可操作语言，容易被当成空洞理想。在要写目标的机构里，它最先被删。
- 世俗化公共服务与它的语言冲突：谈"成长"不如谈"风险等级"好交差。
- 对结构性压迫没有分析。容易把"接纳自己"做成"接受处境"。

**常见误用**　把"无条件积极关注"做成"从不指出问题"。关系很好，事情没动。

## §15 存在主义与灵性实践（existential and spiritual practice）

> 层次：①个案与家庭｜传统：赋权｜证据强度：弱（难测量）｜时间尺度：中—长程

**核心主张**　人必须在没有保证的世界里为自己造意义。恐惧与异化不是症状，是处境的真实回声。灵性关注的是整全与联结——在许多文化里，这本来就是治疗的核心，不是附加项。

**实务动作**
1. **评估灵性与信仰承诺的位置。** 用视觉工具（灵性生态图、灵性生活史图）而不是问卷清单。问的是"它在你的生活里占多大位置"，不是"你信什么"。
2. **先觉察自己的信念。** 避免强加，并主动创造包容——包括对不信的人包容，这一条常被忽略。
3. **以"意义"为焦点提问。** "这件事在你这里意味着什么""还剩什么可以依靠""如果只剩一年，你想先做哪件事"。
4. **在边界经验中陪伴。** 诊断、临终、丧失、迁移、监禁。这些时刻不需要技术，需要有人在场且不逃。
5. **身心一体。** 呼吸、身体、静观、仪式。但不越界为灵性指导——你是社工，不是精神导师。

**代表技术**　灵性生态图／生命史图｜生命回顾｜静观与冥想｜在案主信仰框架内的祈祷与仪式｜身心整合练习｜意义重构

**最适合**　临终与哀伤；重大疾病；移民与少数族裔；存在性危机；成瘾康复中的意义重建。

**失效条件**
- 容易被当成个人偏好而非专业责任，在考核表上无处安放。
- 工作者把自己的信仰带进来，且不自知。这是最常见的伤害方式，也是最难被督导发现的。
- 缺少可界定、可测量的结果，与证据取向对话困难。
- 世俗化公共服务在制度上不支持。它往往只能以"心理疏导"的名义偷偷进行。
- 对东方灵性的兴趣常带后殖民色彩：猎奇式挪用，不了解其脉络，也不承担其社群。

**常见误用**　用工作者的信仰答案去填补案主的沉默。

## §16 社会正义实践与倡导（social justice practice and advocacy）

> 层次：④制度与政策／①个案与家庭｜传统：赋权／社会变迁之间｜证据强度：弱—中｜时间尺度：短（单次—数周）

**核心主张**　正义有两个层面：人际与心理的公平（在关系中被公正对待、身份被承认），以及群体之间与制度内部的正义。倡导是替无权者把利益带到有权者的桌上——但它只借出权力，不转移权力。这一点必须对案主讲清楚。

**实务动作**
九组维度逐一交代，缺一组就会出错：
1. **目标**：个案／议题／系统性。
2. **对象**：个人需求还是集体需求。
3. **场域**：机构内还是机构外。
4. **授权来源**：指示性（只按案主意愿）还是非指示性（按机构决定或专业判断）。选后者必须说明理由。
5. **形式**：正式决策场合还是非正式机会。
6. **案主参与程度**：他到场吗、发言吗、还是只被代表。
7. **方式**：只提供信息与建议／代为陈述／支持他自述。
8. **承诺程度**：代表性（如律师，不必认同案情）还是订阅性（个人深度认同并投入）。
9. **退出条件**：什么情况下停、谁来宣布停。

执行顺序：确认权利依据（法定权益、服务标准、安置决定）→ 整理证据 → 选层级 → 约定"谁来说" → 留申诉与复议的后手。

**代表技术**　个案会议陈述｜申诉与复议｜法定权益告知｜书面报告与证据整理｜与独立倡导者协作｜正常化与社会角色增值｜自助与互助

**最适合**　身心障碍者；精神疾病者；受暴妇女；移民与难民；老年人照护决策；儿童安置。

**失效条件**
- 倡导者保留权力。争来的是这一次的结果，案主仍在请求者的位置。
- 无法赋权给所有人。严重受损、长期被机构化的人需要保护性服务，此时"倡导"可能是另一种形式的替他们决定。
- 不同案主期待的赋权形式不同，一套通用做法不够。有人要你代打，有人只要你坐在旁边。
- 只揭蔽压迫而不改结构：个案赢了，规则没变，下一个人还要再来一次。
- 价值冲突是真实的：案主意愿未必等于其最佳利益；案主可能指定一个有支配性格的亲友代表他；案主偏好可能与机构价值正面冲突。这三种情况都没有干净答案，只有说清楚的取舍。

**常见误用**　工作者按自己的正义判断代替案主提出要求，然后称之为"赋能"。

## §17 赋权（empowerment）

> 层次：①个案与家庭／③社区与组织｜传统：赋权｜证据强度：中（群体赋权有支持）｜时间尺度：中—长程

**核心主张**　权力不能被给予，只能由人自己取得；工作者能做的是移开障碍、补上能力与自信、并把位置让出来。个人困境必须被接回社会结构，否则"赋权"只是让人更好地忍受。

**实务动作**
三步：**减少社会与个人障碍 → 增强能力与自信 → 转移权力**（决策席位、话语权、资源控制）。落到动作：
1. 从案主界定的问题与目标出发，不用机构的分类开场。
2. 分清三类阻塞：制度的（没资格、没渠道）、关系的（家里有人不许）、内化的（"我不配"）。
3. 确认经验与感受。不是安慰，是承认他说的是真的——这一步做不好，后面全是技术。
4. 建参与结构：共同规划、共同评估、共同署名。签名权是最硬的赋权指标。
5. 把个人改变接到集体行动。同类人聚在一起，才可能改变"这是我的问题"这个框架。
6. 对自己的权力保持敏感。每次会后记一句：这次是谁决定的。

**代表技术**　意识提升小组｜参与式规划与评估｜同伴支持／自助团体｜权益倡导｜能力建设｜正常化

**最适合**　受压迫与边缘群体；社区发展；精神健康服务使用者；残障者；受暴妇女。

**失效条件**
- 在个体化实务里常被化约为"帮人解释处境并行动"，不含结构改变；甚至被用来为纯心理干预背书——"提升自我效能"被叫作赋权。
- 对无力取得权力的案主（严重损伤、长期被机构化、临终）失效甚至误导。对他们谈"争取权力"是残忍的。
- 不同案主需要不同形式的赋权，"一套通用赋权理论"不够。
- 可能只揭蔽压迫而不改变它，然后把这叫做"提高了意识"。
- "赋权"一词本身常被机构拿去描述任何一次征求意见，词在这里已经贬值。

**常见误用**　让案主在已定好的方案上"选择"A 或 B，记录为"案主参与决策"。

## §18 批判实践／结构社会工作（critical and structural practice）

> 层次：④制度与政策／③社区与组织｜传统：社会变迁与发展｜证据强度：弱｜时间尺度：长程

**核心主张**　社会问题主要由社会结构与主导群体生成的文化假设造成，个人心理因素次之。支配靠观念而非暴力维持——现状被说成"自然的"，人才会接受它。改变要经过 praxis：行动—反思—再行动，理论与实务互为修正。批判实践的第一项功能是让人不把"现状"当成"必然"。

**实务动作**
1. **从关系与情感投入开始。** 先建立信任，再谈结构。顺序反了就是讲课，案主会点头，然后不来第二次。
2. **把个人处境接到社会分析。** 具体问法："这件事在你身上发生过几次？""你认识几个情况一样的人？""你觉得自己哪里做错了？"——最后一个问题常能暴露内化的责备。
3. **对话式实践。** 平等、开放、不预设结果，防止有制度权力的人提前关闭讨论。你自己就是有制度权力的那个人，所以要主动让出议程。
4. **把案主经验当分析起点，不当素材。** 他的解释是第一手数据，你的理论是第二手。
5. **明确自己的政治与意识形态立场。** 不说清，就是让别人替你决定，而记录里会写成"专业判断"。
6. **在机构约束下找低层收益。** 同时准备承受打压：批判实践在考核体系里通常不受欢迎。

**代表技术**　意识提升（conscientization）｜对话｜praxis 循环（行动—反思—再行动）｜结构性提问（谁受益、谁承担代价、谁不在场）｜叙事与见证｜倡导与行动主义｜政策分析

**最适合**　贫困社区；族裔少数青年；失业者；身心障碍者；精神疾病者；机构层面的服务设计与政策。

**失效条件**
- **不现实。** 多数实务者受雇于政府，法定与政策授权限制了改造空间。写进方案的"结构改变"，落地时常剩一场座谈会。
- 不同批判理论对社会问题的分析彼此不同，选哪个本身就需论证。选错就是把一套现成结论套在案主身上。
- 把权力化约为对个体的控制，会漏掉宗教压迫、人权侵害、家暴等更急迫的议题，缺优先级感。**结构解释不解除当下的保护义务。**
- 难以推导人际实务的处方。它擅长说"为什么不对"，不擅长说"今天下午做什么"。
- 处理情绪与内在议题弱。案主在哭，工作者在讲剩余价值。
- 意识提升假设"看懂了就会有行动"。这个假设经常不成立——看懂了，可能更绝望。
- 只累积批评而缺少正面方案，长期做下去会耗竭工作者。

**常见误用**　把个案会谈变成结构批判讲座。案主点头，问题没动。

## §19 生态实践／绿色社会工作（eco practice / green social work）

> 层次：③社区与组织／④制度与政策｜传统：社会变迁与发展｜证据强度：很弱（新、无公认模型）｜时间尺度：长程

**核心主张**　环境不义是社会不义的一部分。人不是"在社会环境里"，而是在一个物理的、有资源限度的世界里；灾害、污染、缺水、住房退化不是背景，是成因。改变要同时动地方生计与广域环境政策。

**实务动作**
三类议题，动作不同：
1. **地方性议题。** 以地方为基础，回应生计、食物、水、住房、交通、污染与采矿风险。这些是案主每天在谈的事，不需要先说服他们关心气候。
2. **广域政策议题。** 气候灾害、可再生能源、环境规制。通常要与组织、联盟、其他专业一起做。
3. **个人与家庭的整体实务。** 把"整个生活情境"（不止社会关系）作为焦点，做环境影响评估：住哪里、怎么取暖、通勤多久、附近有什么。

每个阶段都问四句：我们如何使用自然环境？能否更好？是否促进可持续？是否提升了对抗灾害／退化／困境的韧性？

**代表技术**　食物援助与社区菜园｜共享居住与工作坊｜冒险教育｜社区能源与保温改造咨询｜地方交换经济与公地安排｜灾害准备与韧性建设｜环境行动主义

**最适合**　受工业、采矿、污染影响的社区；缺水与气候灾害地区；贫民窟与住房退化；青年失业；原住民社区。

**失效条件**
- 概念重叠混乱，没有公认的实践模型。绿色、环境、生态、深层生态几个说法常被混用。
- 鼓励行动主义（基于意识形态或政治理由），但把生态议题纳入日常实务的方法欠发达。结果是"立场很清楚，方法很薄"。
- 处方主要指向与社会工作关联不强的广域政策，难落到日常个案。一个社工站站长很难把它写进年度计划。
- 深层生态的价值立场（人与自然等值）与社会工作的人类福祉中心传统正面冲突。这个冲突没有被解决，只是被回避。

**常见误用**　把"绿色"做成一次社区种菜活动，与污染源和决策过程毫无关系。

## §20 女性主义实践（feminist practice）

> 层次：①个案与家庭／②小组／④制度与政策｜传统：社会变迁与发展｜证据强度：中｜时间尺度：中—长程

**核心主张**　性别关系塑造了经验与机会。在多数社会，女性是社工的主要案主，而社工与照护工作主要由女性承担——这两件事不是巧合。问题来自父权安排与"何为合宜的女人／母亲"的公共定义。改变靠意识提升、对话，以及把私人困扰接回公共议题。

**实务动作**
1. **找共同点，但不抹平差异。** 阶级、族裔、性取向、残障、年龄都在性别之内交错。统一口径的"女性经验"会伤到最边缘的那部分人。
2. **建对话式平等关系。** 防止有制度权力的一方（常是男性，也常是工作者自己）在讨论未展开前就关闭议题。
3. **评估时确保所有议题都被谈到。** 典型场景：一方想把话题锁定在孩子的行为问题上；工作者暂停，请双方同意"逐个孩子列正负项"，从而保留母亲的视角，同时不排除另一方。技术很小，作用是结构性的。
4. **把私人关系与公共定义连起来分析。** 谁做照顾、谁的时间被视为可支配、谁的情绪被叫作"情绪化"。
5. **对"感激／亏欠"做性别分析。** 有人把感激读成负债与依赖，有人读成建立联结的过程。同一句话，两种语法，后面的关系走向完全不同。

**代表技术**　意识提升小组｜对话式访谈｜反身性练习｜性别分析（谁做照顾、谁的时间被算作时间）｜关怀伦理推理｜叙事与见证｜女性主义团体工作

**最适合**　受暴妇女与庇护所；女性照顾者；单亲母亲；性暴力幸存者；女性案主占多数的各类服务。也可用于男性案主：为自己与其他男性的性别歧视负责，并分析男性气质如何形成与改变。

**失效条件**
- 是否排除男性与男性议题（刑事暴力、就业中的剥削、男孩的教育失败）。
- 把女性议题隔离成"特区"。不敢建通用模型，反而使自己不可见，对机构运作的批判也失效。
- 能否作为通用理论存疑：残障、精神健康、犯罪、药物滥用等男女皆受影响或男性为主的领域，硬套会失真。
- "女性有共同经验"的假定会抹平差异。
- 后现代质疑男女二元本身。这个质疑成立，但若因此放弃一切类别，"性别分析"就没法做——这是它尚未解决的张力。

**常见误用**　把"女性视角"做成"多问几句感受"。家庭权力结构一字未动。

## §21 反压迫实践（anti-oppressive practice, AOP）

> 层次：①个案与家庭／④制度与政策｜传统：社会变迁与发展｜证据强度：弱（理论强、实证少）｜时间尺度：长程

**核心主张**　压迫不是个别偏见，是强势群体通过刻板印象与制度安排维持权力的过程。多种压迫交错作用，不可排序、不可累加——种族不压倒年龄歧视，残障不压倒性别。改变要在个人内省、人际、系统三层同时发生，且必须由当事人参与定义什么算压迫。

**实务动作**
六步：
1. **先理解自己如何走到今天的位置。** 我的位置从哪来、靠什么维持。
2. **分析社会正义如何与实务交汇。** 六种正义要素：分配、承认、能力、原住民／后殖民、后现代、宗教灵性。
3. **探索自己与案主的身份、身份群体、压迫与特权。** 两栏都写，只写受压的那一栏是自我美化。
4. **与案主及其社会位置对话。** 理解不义在哪些结构与系统中发生，而不是先假定。
5. **设计三层解放动作。** 内省（我的判断从哪来）／人际（这段关系里的权力）／系统（规则与资源）。
6. **用五个概念落实。** 批判自我反思、参与者受压迫的经验、赋权参与者、伙伴工作、最小干预。

**代表技术**　社会身份与特权检视｜批判自我反思｜交错性分析｜语言检视｜伙伴式规划｜倡导｜机构政策审查

**最适合**　族裔少数群体；移民与难民；残障者；性少数；老年人；宗教少数群体；机构层面的政策与组织改变。

**失效条件**
- 把多种压迫纳入同一框架，可能既不反映特定群体的观点，也无法在不同歧视形式之间设定优先序。最后变成"每个都很重要"，等于没有优先级。
- "政治正确"之讥：聚焦语言与文化容易流于表面。改称呼不改分配，是最常见的空转。
- 与多元文化路线之争：一个要改变利益结构，一个要教育人珍视差异。两条路线在同一份方案里常常互相抵消。
- 把复杂的社会分裂简化成身份清单。清单能用于培训，不能用于判断。
- 实证薄弱。它更像一套伦理立场与自我审查程序，不是一套可检验的干预方法。

**常见误用**　在督导会上检查用词，会后照旧按原规则分配资源。

## §22 多元文化敏感／文化能力实践（multicultural sensitivity / cultural competence）

> 层次：①个案与家庭／③社区与组织｜传统：赋权｜证据强度：弱—中｜时间尺度：贯穿全程（成本低）

**核心主张**　问题常在两套解释框架之间的误读，不在案主内部。文化能力不是背下来的风俗清单，而是在具体情境里分辨"哪些是文化、哪些是处境、哪些是个人选择"的能力。

**实务动作**
1. **建工具箱，但标明它只是假设。** 不同文化对家庭、权威、求助、疾病、死亡的一般取向，用来生成问题，不用来下结论。
2. **辨同质性与异质性。** 同一个人可能同时承受结构性种族不平等、家庭内的性别支配、性取向的压力。三者不能互相替代，也不能互相抵消。
3. **短期工作中优先理解案主自己对其文化经验的解释。** 他的解释比你的知识更接近他的生活。
4. **承认多数群体内部也有多样性。** 同一族群内部，城乡、代际、宗教虔诚度差别可能大于族群之间。
5. **语言适切。** 用口译，不让案主的孩子翻译——那会同时破坏家庭权力与信息准确性。
6. **把自己的文化位置写进评估。** 不是自我表白，是标注你这份判断的偏差来源。

**代表技术**　文化能力训练｜文化家谱图与生态图｜口译与语言适切服务｜节庆与饮食等文化实践的纳入｜社区联络｜文化谦逊式提问

**最适合**　移民与难民；族裔少数群体；原住民；宗教少数群体；跨文化团队与机构。

**失效条件**
- 表面化：只欣赏可见的多样性，不处理实质的不平等。办一场文化节，歧视照旧。
- 忽略范畴内部的差异，把非西方文化置于西方解释之下，简化并否认真实的哲学与实践差异。
- 把文化当不变的整体，假定成员一律接受全部价值。这一条最常伤到年轻人与女性。
- 沦为对"政治正确"的追逐，变成一套话术规范。
- **"文化"常被当作回避结构性解释的托词**：不去问为什么这个群体失业率更高，只说"这是他们的文化"。

**常见误用**　用"这是他们的文化"结束评估，从此不再问任何问题。

## §23 原住民实践（indigenist practice）

> 层次：③社区与组织／④制度与政策｜传统：社会变迁与发展｜证据强度：弱（模型不成熟）｜时间尺度：长程

**核心主张**　原住民的身份来自与土地、语言、亲属与历史的具体联系，也来自被殖民的经历。需要不能由外部定义。实践必须从自我认同与自决出发，而不是从"为他们设计服务"出发。

**实务动作**
1. **以社群自身的叙事与知识为起点。** 叙事在此的作用是把个人故事接到文化脉络上——不是把文化当背景，是把文化当解释框架。
2. **把殖民与后殖民结构写进评估。** 不是背景段，是成因段：土地被占、语言被禁、儿童被带走、福利被附条件。
3. **支持社群守护自然与文化的角色。** 土地议题与文化议题在这里是同一件事。
4. **确保服务由原住民组织主导或共同治理。** 不是"邀请代表参加"，是决策席位的分配。
5. **交接与退出按社群节奏，不按项目周期。** 项目结束不等于关系结束；硬撤出会造成二次抛弃。

**代表技术**　叙事与见证｜社区主导的参与式评估｜文化仪式与语言复兴｜土地与生态项目｜集体倡导｜跨代创伤工作

**最适合**　原住民社群；被寄养／收养的原住民儿童；土地与环境争议；文化与语言流失。

**失效条件**
- 被主流机构吸收为文化装饰，而不转移权力。开幕式请长者致辞，决策会上没有他们。
- "原住民"范畴内部差异极大，统一处方必然失真。不同社群的历史、语言、与国家的法律关系都不同。
- 与通用标准化评估工具冲突：工具假定的是个体而非社群，是症状而非历史，是当下而非跨代。
- 实践模型本身不成熟。很多做法是从叙事、生态、反压迫嫁接来的，用在具体个案上时应当说明这是推断，不是成熟方法。

**常见误用**　把"文化敏感"做成一套仪式流程，权力与资源分配一字未动。

## §24 理论组合的规则

组合不是把好东西加在一起。多数"整合取向"的方案失败，不是因为某个理论不好，而是因为两套理论对"问题在哪、谁该变"给出了互斥答案，案主同时收到两个指令，于是两个都不执行。

### 24.1 五条硬规则

1. **一次只有一个改变理论。** 其余理论只能当定位工具（看清局面）或交付工具（怎么把事办成）。同时宣布两个改变理论，等于没有理论。
2. **同层可换，跨层必分工。** 个案层的两套理论可以按阶段替换；跨层的组合必须写成"谁做哪一段、产出什么、什么时候交接"。
3. **数量门槛。** 1–2 个：默认，不必解释。3 个：必须用一句话说明各自管什么。4 个及以上：必须写成阶段表，每阶段只留一个主理论——否则是堆砌，不是整合。
4. **价值取向相反的不能同时当主。** 一个要案主适应现实，一个要改变现实，只能一个做主、一个做备注，且必须对案主说明这个取舍。
5. **过"案主听得懂"测试。** 说不清"这周为什么谈这个、下周为什么做那个"，就是工作者自己在拼贴。

### 24.2 能搭的组合（照此写分工）

| 组合 | 怎么分工 | 前提／注意 |
|---|---|---|
| 危机介入 ＋ 任务中心 | 危机期只做稳态与安全，2–6 周后转任务中心处理持续问题里的优先项 | 交接要明说，否则案主以为被抛弃 |
| 动机式访谈 ＋ 任务中心 | 一个管"要不要动"，一个管"动了以后做什么" | 一旦进入行动阶段，平衡位就该收 |
| 动机式访谈 ＋ 认知行为 | 一个做动机与联盟，一个做技能与作业 | 动机不足时上作业，脱落率极高 |
| 依恋 ＋ 优势 | 一个定"谁需要安全基地"，一个定"这个家里已经有什么" | 优势不能替代风险评估 |
| 依恋 ＋ 系统 | 一个看照顾关系质量，一个看照顾网络里还有谁 | 两者都容易把母亲当成唯一责任人 |
| 系统 ＋ 任务中心 | 系统定目标系统与行动系统，任务中心给执行序列 | 系统定完层就别再扩大范围 |
| 优势 ＋ 寻解 | 优势是底色（怎么看人），寻解是方法（怎么谈） | 同族，合用不算"两个理论" |
| 叙事 ＋ 女性主义／反压迫 | 一个做外化与重写，一个解释"这个故事为什么被写得这么顺" | 只做叙事会个体化，只做结构会没有语言 |
| 赋权 ＋ 倡导 | 赋权定方向（权力转移），倡导是当下的技术（把事办成） | 每次倡导后问：案主的位置有没有前移 |
| 批判／结构 ＋ 任务中心 | 结构分析定"改什么"，任务中心定"这周做什么" | 必须防任务把结构问题改写成个人待办 |
| 社会教育学 ＋ 依恋 | 日常结构提供安全基地，教育性活动提供成长 | 需要稳定的照顾者团队；流动率高就塌 |
| 生态 ＋ 宏观／社区工作 | 一个定议题（环境不义），一个给组织方法 | 别停在种菜与宣传 |
| 多元文化 ＋ 反压迫 | 一个管"读懂"，一个管"谁的利益被动了" | 顺序不能反：先读懂再谈结构，否则变成讲课 |
| 原住民实践 ＋ 叙事／生态 | 自决定谁做主，叙事接历史，生态接土地 | 三者都不能替代"把决策权交出去" |

### 24.3 会互相抵消的组合

| 组合 | 冲突点 | 若必须同时用，怎么救 |
|---|---|---|
| 认知行为 × 批判／结构 | 一个说问题在思维，一个说问题在制度。案主同时收到"是我想错了"与"是制度错了" | 分层写：认知行为只做症状与技能，结构分析只做环境改造，并明确告诉案主这是两件事 |
| 心理动力（洞见／长程）× 任务中心／危机 | 时间框架与"问题视为给定"直接冲突：一个要拉开，一个要收口 | 不在同一阶段用；危机期绝不做洞见工作 |
| 优势／寻解 × 儿童保护风险框架 | 正向取向会稀释风险判断，把"他有优势"读成"风险可控" | 风险框架永远优先；优势只用于设计干预方式，不用于定风险等级 |
| 动机式访谈的平衡位 × 法定强制 | 一边说不强加目标，一边必须强加 | 把目标与方式分开：目标由法律定，路径由案主选，并把这个区分当面说明 |
| 依恋 × 认知行为（儿童个案） | 一个要改照顾环境，一个要改孩子对环境的反应 | 先环境后孩子。顺序颠倒等于把责任放在孩子身上 |
| 系统（适应／契合）× 批判（改造结构） | 一个要案主适应现实，一个要现实改变 | 只能一个做主。若做系统，必须同时说明"这条现实是不义的" |
| 赋权 × 代表性倡导 | 一个要转移权力，一个由工作者代为陈述并保留权力 | 明确"这次是代打"，并约定下一次谁来说 |
| 人本（非指导）× 任务中心／机构筛查 | 一个拒绝预设目标，一个必须预设目标与时限 | 关系建立期用人本，进入契约期切换，并解释为什么切换 |
| 社会教育学（集体、日常）× 个案管理（个体、配额、时限） | 一个以共同生活为单位，一个以个案为单位 | 用集体活动承载个案目标，但别把集体活动拆成 KPI |
| 存在／灵性 × 标准化短程方案 | 目的不同：一个要意义与整合，一个要症状下降 | 可以并行，但不能用症状量表去证明意义工作的价值 |

### 24.4 组合的最小写法（三句话）

任何方案出现两个以上理论，写这三句就够，不必附理论综述：

1. **主**：本阶段用 ___，因为它解释 ___ 这一层，且案主在此有能力参与。
2. **辅**：___ 只用于 ___（定位／关系／交付），不承担改变任务。
3. **界**：若出现 ___（风险升级／动机不足／结构卡死），切换到 ___，并在记录里写明切换理由。

### 24.5 一条反规则

**不要在同一个案子里同时做"理解"与"纠正"。** 理解（动力、叙事、人本、灵性）与纠正（认知行为、任务中心、行为管理）可以先后，不能在同一句话里并存。案主分不清你是在听他，还是在改他；一旦分不清，他就只给你看你想看的那部分——那时你手上所有的评估都是假的。
