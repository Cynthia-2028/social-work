# 社会工作（Social Work）

一个用于社会工作知识科普、现象解读、专业答疑、系统学习、选题探讨、论文写作与论文评审的知识库与工作流。

核心设计只有一条：**先定系统层次，再谈方法。**

社会工作实务里绝大多数错误不是技术不够，而是**问题与介入层次错配**——把制度造成的困境当作个人适应不良来辅导，或反过来把一个人眼下的险境化约为结构批判。层次定错了，技术越熟练，浪费越大。

---

## 四层系统

| | ① 个案与家庭 | ② 小组 | ③ 社区与组织 | ④ 制度与政策 |
|---|---|---|---|---|
| 一句话 | 一个人/一个家怎样过下去 | 一群人在一起能发生什么 | 一片地方的人如何组织起来 | 规则、资源与权利如何分配 |
| 改变的媒介 | 关系与对话 | 同伴互动与小组结构 | 组织、联盟、行动 | 证据、议程、谈判 |
| 最强处 | 把"过不下去"变成下一步 | 用互动本身当改变媒介 | 能改变资源与关系的位置 | 能改变规则本身 |
| 软肋 | 容易把结构问题个人化 | 容易被当作廉价批量方案 | 见效慢、易被紧急个案打断 | 燃眉之急等不起 |

七类任务共用这一套路由：知识科普 / 现象解读 / 专业答疑 / 系统学习 / 选题探讨 / 论文与文书写作 / 质量评审。

## 怎么用

**问概念**（"什么是优势视角"）
→ 直接答，给定义 + 一个可判断的例子 + 一个常见误读。术语查 `17`。

**解读现象**（"怎么看待××现象"）
→ 先定位层次，再用 `14` 的六要素框架走一遍，给两个以上竞争解释。

**做介入设计**（"这个社区/这个个案该怎么办"）
→ 先问层次，按 `02` 定位，再进 `06`/`08`/`09`/`10`；填 `assets/intervention-canvas.md`。

**写论文**（"帮我写/改这篇"）
→ `15` 的七件套逐件过；投稿前用 `assets/checklist.md` D 部分。

**评论文/方案**（"看看这篇有没有问题"）
→ 先判层次与结论类型，再套 `16` 的六维量表，分开给分。

## 四条铁律

1. **先定层次，再谈技术。** 同一个"孩子不想上学"，四层都可以是真的，但不能同时作为介入点。
2. **价值判断是前置条件，不是附录。** 谁受益、谁受损、谁同意了、谁有能力说不。
3. **优势与需求必须并置。** 只讲需求制造依赖，只讲优势掩盖剥夺。
4. **说清判断能说到多硬。** 描述／机制／因果／规范，四类说法不能互相顶替。

## 边界

- 不做临床诊断、不给用药建议、不出法律意见。
- 涉及自伤、伤人、虐待、家暴时，**先评估即时安全并按所在地法规履行报告义务**；本知识库只提供分析与沟通框架，不替代危机处置流程。
- 法律与政策内容只给一般性表述，**以使用者所在地现行法规与机构规程为准**。
- 中国场域部分基于个案研究，属机制假说，不可普遍化。

详见 `references/audit.md`。
