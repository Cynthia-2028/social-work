# 一页纸介入设计画布

用法：打印或复制到编辑器，逐格填写。**空格不能留白**——留白的那一格就是方案会在执行时塌掉的地方。

---

## A. 定位（不填完不要往下走）

| 项目 | 填写 |
|---|---|
| 现象（一句，可指认） | |
| 这次要改变的**具体对象**（一个人/一组人/一个地方/一条规则） | |
| 层次（①个案家庭 ②小组 ③社区组织 ④制度政策） | |
| 为什么是这一层（不是别的层） | |
| 若只做这一层，最坏的副作用 | |
| 谁在这个方案里**没有位置** | |

---

## B. 判断依据

| 项目 | 填写 |
|---|---|
| 当事人（或社区）自己最想先动的一件事 | |
| 我判断他需要的（与上一条若不同，说明为什么） | |
| 支持我判断的证据（≥2 项，注明来源类型） | |
| **反对我判断的证据**（≥1 项，必须填） | |
| 这个判断能被什么推翻 | |

> 「反对证据」栏是本画布的承重墙。填不出，说明目前的判断是印象，不是评估。

---

## C. 价值与伦理前置四问

| 问题 | 填写 |
|---|---|
| 谁受益 | |
| 谁受损（含机会成本） | |
| 谁同意了（怎么同意、有无替代同意） | |
| **谁有能力说"不"，说了会有什么后果** | |

若第四问答不出，方案需要先补一个反驳渠道，再谈执行。

---

## D. 目标（一个目标一行，不超过三个）

| # | 目标（正向语词表述） | 谁来判断达成 | 判据（可观察） | 时限 |
|---|---|---|---|---|
| 1 | | | | |
| 2 | | | | |
| 3 | | | | |

**自查**：每个目标是否同时满足——具体、可观察、当事人认可的、可行、有时限、正向表述、不依赖我一直在场。

---

## E. 任务与分工

| # | 做什么 | 谁做（当事人/我/第三方） | 何时 | 卡住了找谁 |
|---|---|---|---|---|
| 1 | | | | |
| 2 | | | | |
| 3 | | | | |

**自查**：如果"谁做"一栏多数写的是"我"，这不是介入计划，是服务清单。

---

## F. 基线与监测

| 项目 | 填写 |
|---|---|
| 基线方法（频次计数 / 回溯估计 / 自锚量表 / 关键事件） | |
| 测量什么（具体行为或事件，不要测"状态"） | |
| 测量间隔 | |
| 谁记录 | |
| 若基线无法建立，替代方案 | |

---

## G. 风险与保护

| 项目 | 填写 |
|---|---|
| 即时安全风险（自伤/伤人/被伤害/失去住所/断药/失学） | |
| 报告义务是否触发（以所在地法规与机构规程为准） | |
| 出现风险时的**第一步动作**（谁、几分钟内、打给谁） | |
| 我自己的支持（督导/同事/转介） | |

---

## H. 结案条件与结束处理

| 项目 | 填写 |
|---|---|
| 什么情况下算完成（对应 D 的目标） | |
| 什么情况下算中止（非达成） | |
| 结束时必须完成的三件事 | ① 巩固： ② 泛化： ③ 处理"关系结束"本身： |
| 随访安排（只给间隔，不给具体日期） | |

---

## I. 一句话总结（给机构/资助方看的那一句）

```
本次介入在【层次】上，通过【媒介】，目标是【目标1】，判断依据是【核心证据】，
主要不确定性是【最大风险】。
```

> 写不出这一句，说明方案还停在想法阶段。

---

## J. 五个最后检查

1. 这份方案里，**当事人做过哪些决定**？
2. 如果我一夜之间消失，留下的是**能力**还是**空缺**？
3. 这个方案能不能被**反驳**？谁能反驳？
4. 三个月后回看，我会希望当初动的是**这一层**吗？
5. 我有没有为了让它看起来完整，而删掉了那个"还不知道怎么办"的部分？
